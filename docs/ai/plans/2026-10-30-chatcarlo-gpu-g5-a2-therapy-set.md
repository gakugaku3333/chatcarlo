## 0. 前提事実（2026-10-30 に確認）

### 0.1 P7 と P8g-2 は物理の世代が違う

```
prototypes/mv_electron/gpu/p7_kernel.h:  #include "p5j_kernel.h" / "p5b_wrap.h" / "p7_field.h"
prototypes/mv_electron/gpu/p7_field.h:   #include "p6_field.h"
prototypes/mv_electron/gpu/p8g2_kernel.h:#include "p8g_kernel.h"
prototypes/mv_electron/gpu/p8g_kernel.h: #include "p8g_materials.h"
prototypes/mv_electron/gpu/p8g_materials.h: #include "p8g_functions.h"
```

- P7 の核 = P5j の遷移（水だけの表 `P5jTables`）＋ P6 の発散する照射野と区画の採点。
- P8g-2 の核 = P8 の材料の表（`P8gMaterial`、多材料）＋ 状態機械。照射野・横方向の採点はない。
- 物理の違いは蛍光・全殻の緩和だけではない。衝突阻止能が、P5j では解析式（`p5j_terms.h:29`）、P8 では ESTAR の表の補間（`p8g_materials.h:19`、`photon_transport_p8e.py:700`）。水でも P7 と同じ結果になるとは限らない（Codex 1 巡の指摘 2）。
- **先例**: P8g-2 の写しから作った P9b の核で、10 MV・5×5 cm²・2,000 万履歴の水を P7 条件 A の EGS5 と比べ、J1〜J3 は合格（`docs/validation/mv/p9b/RESULTS.md:94-100`）。条件 B・C は P8 の物理では未照合。P9b は幾何が違い、段階全体は不合格のまま。**この先例で A2 の合格の代わりにはしない**。

### 0.2 2 つの駆動は同じ骨格（Codex 1 巡の指摘 1。Claude が現物で確認）

`p7_gpu.cu:35-50` と `p8g2_gpu.cu:20-45` は、どちらも同じ流れである。

1. `atomicAdd(next,1)` で履歴を取る。
2. 相を snapshot し、`__ballot_sync` で 4 つの相に分ける。
3. その相を 1 歩進める。
4. 履歴が終わったら出力し、その場で次の履歴を補充する。

違うのは、状態の持ち方（`P7Slot` と `P8g2State`）、初期化、出力・集計の形だけ。親計画 D13 の「P7 の形と P8g-2 の形を比べる」は、**比べる駆動が 2 つ存在しない**。
