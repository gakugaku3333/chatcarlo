5. **【参考】棄却は、エネルギーヒンジを含む完全な「何も起きなかった衝突」ではありません。**

   [ELECTR:520](/Users/oishifamily/Projects/viveMonte/docs/egs5_crosscheck/egs5/egs/egs5_electr.f:520)で、COLLISに入る**前**に、

   ```fortran
   e(np) = e(np) - deinitial + denstep
   deresid = 0
   deinitial = 0
   denstep = 0
   ```

   としています。したがってIARG=12で保存するエネルギーは、既にヒンジを打ち切ってCSDAエネルギーへ調整した値です。元の`deinitial/deresid/denstep`と、それに対応する`eie`等をこのコールバックから復元することはできません。棄却後も、新しいエネルギーヒンジを設定します。硬衝突前にこの調整を行うことは[EGS5マニュアル§2.15.5](https://rcwww.kek.jp/research/egs/egs5_manual/slac730-160113.pdf)にも説明されています。
