# Codexのレビューと実装報告の原文

計画ファイルのヘッダにある「Codexレビュー: N巡（致命・実質…）」の根拠となる原文を、計画ごとに保存する。
`codex exec -o` の出力をそのまま置いたもので、絶対パスだけをリポジトリ相対に置き換えている。

- `<計画名>.reviewN.md`: N巡目のレビュー（read-only）。
- `<計画名>.impl-report.md`: 実装完了時の最終報告。途中で利用上限により中断・再開した計画では、再開後の報告のみ残っている。

P1とP1bの中断前の報告は、Codexが最終応答を出す前に利用上限で止まったため存在しない。
