**この試作は進める価値があります。ただし、現在の骨子のままでは「不一致の原因」と「本番計算の単価」を十分に切り分けられません。** 特に修正が必要なのは、放射損失の比較条件、多重散乱・境界処理の定義、K1〜K6が検証する範囲、性能見積もりへの接続です。

指定文書、親計画、EGS5のソースとマニュアルを読みました。ファイルの変更・計算の実行はしていません。以下は、10月12日までの開発試作としての評価です。**致命の指摘はありません。**

枠組みについての所見を別に述べると、治療領域拡張を先に試し、期限で未完了を含めて判断材料を返す方針は、ユーザーの優先順位に合っています。ただし、この期間で直接測れるのは「選んだ電子輸送方式を実装・検証する難しさ」と「その実装の費用」です。連成輸送全体の完成期間まで実測したことにはなりません。未測定部分の幅を残して報告すれば、この試作の目的は達成できます。

**1. 【実質】光子を破棄するだけでは、放射損失の比較条件が揃わない**

対象：[制動放射の扱い](docs/ai/plans/2026-10-07-mv-p1-electron-prototype.md:48)。

試作側は非制限の放射阻止能をすべて「放射として脱出」に計上します。一方、通常のEGS5では、

- AP未満：制限放射阻止能として連続エネルギー損失に含まれる。
- AP以上：制動放射光子として明示生成される。

という分担です。生成光子の破棄で取り出せるのは後者だけです。前者を通常のEDEPとして沈着に加えると、比較する量が異なります。これは[SPTOTEとBRMSTMの実装](docs/egs5_crosscheck/egs5/pegs/pegs5.f:5014)から確認できます。

**EGS5本体を変更せず光子を破棄することは可能です。** ただし、PCUTを高くする方法でも、HOWFARでユーザー破棄する方法でも、EGS5はそのエネルギーをEDEPとして通知します。ユーザーコードで放射脱出へ振り分ける必要があります。[PHOTONの破棄処理](docs/egs5_crosscheck/egs5/egs/egs5_photon.f:322)。生成直後のAUSGABを使う場合も、光子が常にスタック最上段にあるとは限りません。

具体的な選択肢は次のとおりです。

| 比較条件 | 利点 | トレードオフ |
|---|---|---|
| 通常のEGS5で生成光子を破棄し、AP未満の放射損失も沈着から分離 | 通常輸送との接続が明確 | 試作の連続放射損失と、EGS5の離散放射損失の差が残る |
| EGS5側も放射損失をすべて連続化し、沈着から分離 | 今回の散乱・境界・衝突損失を比較しやすい | 特殊な比較設定の成立確認が必要 |

後者の候補として、配布ソースの`IUNRST=4`は「制限衝突＋非制限放射阻止能、明示Møllerあり、明示bremsなし」を構成しています。ただしマニュアルはIUNRST変更を通常のEGS実行用データ生成に推奨していません。**ソース上の経路はありますが、今回使える設定として実行確認済みではありません。** もう一つは通常設定でAPを入射電子の最大運動エネルギー以上にして放射を連続化する案です。こちらもPEGS生成・fit・輸送の確認が必要です。

いずれも、連続EDEPから放射分を分離するときは、EGS5が実際に使った阻止能・エネルギー評価に合わせて帳簿を閉じる必要があります。ESTARの値を後から一律に差し引く方法では不十分です。

**2. 【実質】random hingeと境界横断の選択が、試す方式の定義としてまだ不足している**

対象：[方式](docs/ai/plans/2026-10-07-mv-p1-electron-prototype.md:40)。

**GS角度分布とrandom hingeの組み合わせ自体に矛盾はありません。** ただし、通常のrandom hinge、散乱強度に基づくmodified random hinge、EGS5のdual random hingeは、同じ実装ではありません。

EGS5はエネルギー損失と角度散乱に独立したhingeを持ち、境界では残りのエネルギー損失量・散乱強度を保持して先へ進みます。単に「境界でステップを切り、角度を再標本化する」方式とは違います。[EGS5マニュアル §2.15](https://www.slac.stanford.edu/pubs/slacreports/reports16/slac-r-730.pdf)。

骨子で次を選んでおく必要があります。

- hingeを道のりの一様乱数で置くか、積算散乱強度で置くか。
- ステップ中のエネルギー変化をGS表にどう反映するか。
- 境界・明示Møllerで中断されたhingeの残量を保持するか。
- 散乱後の直線区間についても、境界距離を計算し直すか。

短いステップの通常random hingeを採用することも、この試作では許容できます。ただし結果は「その方式・その刻み幅で成立」と解釈します。本番候補がdual random hingeなら、通常hingeの実績から本番の難しさを直接推定できません。

**3. 【実質】K1だけでは、クラスIIの衝突損失が正しいことを確認できない**

K1は非制限衝突阻止能の照合です。しかし輸送で使うのは制限衝突阻止能と明示Møllerです。非制限値が一致しても、両者の分担に欠落・二重計上が残り得ます。

最低限、同じMøller微分断面積について、

\[
S_{\mathrm{col,unrestricted}}
=
S_{\mathrm{col,restricted}}(T,\Delta)
+
n_e\int_{\Delta}^{T/2}W\,\frac{d\sigma_{\mathrm M}}{dW}\,dW
\]

を確認する条件を追加するのが適切です。さらに、明示事象の率、二次電子のエネルギー分布、両電子の角度と収支を単体で照合します。

AEの記述も修正が必要です。EGS5のAEは**電子の全エネルギー**で、二次電子の運動エネルギー閾値は概ね`Δ=AE−RM`です。`AE=0.521 MeV`なら約10 keVであり、「AE以上の衝突損失」ではありません。電子の最大移行エネルギーは`T/2`です。

一方、**公表式にESTARのI値と密度効果δ(T)を入れる方針は成立します。** δを含む非制限式から、同じMøllerモデルのhard損失積分を引く構成なら、分担も明確です。δを二重適用せず、運動エネルギー・単位・補間規則を固定してください。

**4. 【実質】自己整合試験に、GS表そのものを独立に検査する条件が必要**

K5・K6は境界依存性と刻み幅依存性を調べますが、誤った角度分布を同じように使い続けても通過できます。T2の「単体で照合する」を、総合判定の必須条件へ接続する必要があります。

軽い追加で十分です。

- GS表の規格化、CDFの単調性、無散乱確率。
- 固定エネルギーでのLegendreモーメント  
  `〈Pℓ(cosθ)〉=exp(−sΣℓ)`、少なくともℓ=1,2。
- 短距離での単一散乱極限。
- 代表点で、同じ断面積を使った逐次単一散乱との比較。

この検査はEGS5に依存せず、表生成・補間・標本化の誤りを検出します。GSは角度分布の理論なので、hingeによる位置更新は別に検査します。横変位の二次モーメントか、固定深さの横方向広がりを少数点追加すれば、「多重散乱の中核」の評価が深さ線量だけより強くなります。

**5. 【実質】EGS5のステップ感度は、複数の制御を分けて確認する必要がある**

T1で設定を確認する方針は正しいです。ただし、単一の「ステップ制御変更」では安定性を十分に検査できません。

EGS5では少なくとも次が別です。

| 設定 | 主な役割 |
|---|---|
| `USEGSD` | GSかMolièreかの選択 |
| `CHARD`、`EFRACH/EFRACL` | 多重散乱の刻みの選定 |
| `K1HSCL/K1LSCL` | 散乱強度の地域別スケーリング |
| `ESTEPR` | エネルギーhingeの刻みのスケーリング |
| HOWFAR | 各直線移動区間の境界制限 |

`CHARD`は最大直線ステップ長ではありません。採点・形状の細かさを表す長さから、許容する散乱強度を選ぶための値です。また、配布初期値は`USEGSD=0`なので、P0でGSを使ったとは読み替えられません。[初期値](docs/egs5_crosscheck/egs5/egs/egs5_block_data.f:37)。

K3では、多重散乱の刻みとエネルギーhingeの刻みを**別々に**細かくするのが適切です。実際の刻み分布が変わったことも確認します。GSを選ぶ場合は生成表・fit・使用範囲も記録してください。P0の電子fit警告への対応とは別の確認です。

**6. 【実質】T6から本番の時間幅・期間幅を更新する方法が不足している**

電子単独試作から、Numbaの実ステップ単価は測れます。ただし、それをP0のEGS5ステップ数へ直接掛けると、異なるステップ定義・制御を混ぜます。

今回、具体的に測るべきものは次です。

- JIT除外のwall time/一次電子。
- 直線移動区間数、GS標本化回数、Møller回数。
- 採点あり／なしの差。
- 2 MeVと10 MeV、採用刻みと細かい刻みでの変動。
- 表生成・初期化時間、表とスタックのメモリ。

平均ステップ単価だけでなく、これらの内訳があると本番への外挿ができます。10 MeVを物理合否に使わなくても、性能計測には使うべきです。

期間は、データ・表・輸送・境界・検証ごとの作業時間と手戻りを記録し、**実装済み部分だけを実績で置き換える**のが妥当です。陽電子、制動放射、連成、統計精度に必要な履歴数は未測定の幅を残します。

また、K3未達で「停止」とすると、独立に可能なT6まで止まるように読めます。停止対象を「EGS5を基準とするK4の判定」に限定し、自己検査と性能測定は期限まで可能な範囲で続ける方が目的に合います。

**7. 【軽微】K1〜K6の閾値は概ね妥当だが、判定の定義を固定する必要がある**

数値幅を一律に厳しくする必要はありません。

| 条件 | 評価と必要な補足 |
|---|---|
| K1：1% | 同じ物理式・入力の実装照合として妥当。制限阻止能の分担検査を追加する |
| K2：10⁻⁶ | 妥当。全体残差に加えて履歴別最大残差を保存し、相殺を検出する |
| K3：1% | 基準側の安定性として妥当。統計不足を合格に数えない |
| K4：3% | 期限付き試作として妥当。基準線量、評価bin、R50・Rpの抽出法を固定する |
| K5：1% | 妥当。同じ採点binを保ち、輸送境界だけを追加する |
| K6：1% | 妥当。散乱・損失のどの制限を半減したか明記する |

R50・Rpには、下降側の補間、Rpの接線フィット範囲、背景の扱いが必要です。たとえばR50が1 cmなら3%は0.3 mmなので、binと抽出法の分解能が判定を支配しないようにします。

「統計誤差内」は、差が有意でなければ合格、という意味にしないでください。低統計ほど通りやすくなります。差の不確かさを報告し、許容幅に対して十分な精度を要求する必要があります。最大線量も、コードごとにノイズを含む最大binを選び直さず、基準計算の固定定義を使います。これらは詳細版で固定すると明記済みなので、骨子段階では軽微としました。

**8. 【参考】遮蔽RutherfordをGSで使うことは成立するが、散乱断面積の近似は残る**

GSを使えば、与えた断面積から角度分布を構成できます。しかしGSにしただけで、遮蔽Rutherford断面積が精密な電子弾性散乱モデルになるわけではありません。EGS5のGS経路はpartial-waveデータを使います。

この試作で遮蔽Rutherfordを採用することは許容できます。H/Oの数密度による合成、全角度域の断面積の形、soft電子散乱の扱いを明記し、EGS5との差にモデル差が含まれると記録してください。**不一致だけからNumbaやhingeが難しいと結論しない**ことが要点です。

**9. 【参考】2 MeVを合否、10 MeVを参考にする判断は妥当**

放射損失の揺らぎを省く今回の試作には適しています。ただし、放射寄与が小さいことだけでは、R50・Rpや下降部の差が3%未満になる保証にはなりません。連続／離散放射の感度をEGS5側で少数条件確認できれば、解釈が明確になります。

2 MeVでは減速後の低エネルギー散乱も効きます。合格の名称は「2 MeV水・指定条件で電子輸送試作が成立」程度が適切です。10 MeVで不一致が残っていても、この試作の成果は否定されません。

**10. 【参考】ESTARの1%照合は物理精度1%の保証ではない。Fano任意も許容される**

ESTARのδとIを使った式の照合は、独立した実装経路の検査になりますが、独立した基礎物理データとの照合ではありません。NIST自身も低エネルギーで大きめの不確かさを示しています。K1は実装整合性として解釈すれば問題ありません。[NISTの方法と不確かさ](https://physics.nist.gov/PhysRefData/Star/Text/method.html)。

Fanoを今回任意にすることも、均質水の期限付き試作として許容されます。親計画のFanoゲートを満たしたことにはしない、という境界を保てば十分です。

同じ目的を達成する代替設計としては、次を勧めます。

| 案 | 具体的な構成 | 得られる答え／トレードオフ |
|---|---|---|
| **推奨：現行候補を段階検査する** | GS表の解析検査 → 固定エネルギーの角度・変位 → クラスII損失 → 境界 → EGS5深さ線量。放射は比較専用の連続条件を揃える | 本番候補を保ち、失敗箇所を特定しやすい。準備は少し増えるが原因調査を短縮できる |
| 短いステップの通常random hinge | エネルギー損失比と散乱強度に明示上限を置き、境界で短縮する | 実装が単純。ステップ数が増え、dual random hingeの単価・難しさは測れない |
| 単一散乱を小さな参照系にする | 代表的な固定エネルギー・短い水スラブだけ逐次散乱する | GS・位置更新の独立検査に有効。全深さ線量の主方式にすると高価 |
| ESTAR非制限損失によるクラスI試作 | δ線を生成せず、散乱と連続損失のみ測る | 最も速く形になる。ただしクラスII、二次電子スタックの難しさ・費用に答えられず、今回の主案の代替としては弱い |

**推奨案なら、方式の難しさには直接答えられます。単価も実測できます。全体期間については、実績で置き換えられた部分と残る仮定を分けることで、過大な確約をせず見積もり幅を狭められます。**
