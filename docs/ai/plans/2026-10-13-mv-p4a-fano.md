## 1. 核 `photon_transport_p4.py`

`photon_transport_p3b.py` の `_run_coupled`・`run_coupled` を写して、次だけを足す。物理の式、乱数を引く順序、事象の優先順位は変えない。

### 1-1. 追加する引数（`run_coupled` のキーワード。すべて既定値では元と同じ動作）

| 引数 | 既定 | 意味 |
|---|---|---|
| `layer_faces` | `None` | 面の深さ [cm]、昇順、先頭0、末尾は `thickness` に一致。`None` は `[0, thickness]` |
| `layer_rho` | `None` | 層ごとの密度の比（水=1に対する倍率、正、有限）。長さは面の数−1。`None` はすべて1 |
| `mass_bin` | `None` | 質量厚さの採点の区切り幅 [g/cm²]。`None` なら質量厚さの採点をしない |
| `fano_source_T` | `None` | 質量あたり一様・等方の荷電粒子の線源の運動エネルギー [MeV] |
| `fano_source_charge` | `-1` | −1 電子、+1 陽電子 |
| `history_rng` | `False` | 真なら、履歴 h の先頭で `np.random.seed((seed+h) % 2**32)` を呼ぶ |
| `record_histories` | `False` | 真なら、履歴ごとの質量厚さの区切りの沈着 `(n, nmass)` を返す |
| `fault` | `0` | 試験専用。1: 弾性散乱の `total`・`G1` に密度をかけない。2: 連続の阻止能 `S` に密度をかけない。0以外は `run_p4a.py` のA4と試験からだけ使う |

検証（違反は `ValueError`）: `layer_faces` と `layer_rho` は両方 `None` か両方指定。層を指定したときは `regions`・`record_deposits`・`field_half`・`infinite_medium` と併用不可。`mass_bin` は、すべての面の質量厚さ（下記）が `mass_bin` の整数倍（相対 1e-9 以内）であること。`fano_source_T` は他の線源（`source_state`・`charged_source_T`・`positron_source_T`・スペクトル）と併用不可、`mass_bin` が必要。`fault` は 0・1・2 のみ。

### 1-2. 密度の扱い

質量厚さ: `m_faces[0]=0`、`m_faces[i+1]=m_faces[i]+rho[i]*(faces[i+1]-faces[i])`。層 `r` の中の深さ `z` の質量厚さは `m_faces[r]+rho[r]*(z-faces[r])`。

- 電子・陽電子: 率のキャッシュ（`cached_ev` の中）には密度1の値を入れたままにし、ステップごとに層の密度 `q=rho[region]` をかけた値を使う: `S*q`、`rate*q`、`total*q`、`G1*q`、`brate*q`、`bsoft*q`、`arate*q`。事象までの距離（`eb`・`mb`・`hb`・`rb`・`ab`・`a[6]/S`）、損失 `loss=step*S`、残りの量の更新、`radiation`、`expected_n` のすべてで密度つきの値を使う。`bhard` を cm あたりの量として使う箇所があれば同じく密度倍（`bhard/brate` の比は変えない）。
- 角度・エネルギーの標本化、`scattering_hinge` に渡す `total`・`G1`（比としてしか使われないことを確かめ、そうでなければ密度つきを渡す）、無次元の残りの量、しきい値（`CUT`、`DELTA`、`1e-13`、`1e-14`）、制動放射の `shape`・包絡は変えない。
- 光子: 係数 `c` の各成分に密度をかける。自由行程は光学的な厚さで持つ: 相互作用のたびに `tau=-ln(u)` を1回だけ引き（乱数を引く位置は元と同じ: 飛行の直前）、層の中で `length=min(tau/mu_layer, bb)` 進み、内部の面に達したら `tau` を進んだ分だけ減らして次の層で続ける（乱数を引き直さない）。外側の面（先頭・末尾）に達したら元と同じく流出。カーマの集計（`score_kerma`）は層の密度つきの係数で行う。
- 光子の相互作用・制動放射・消滅で生まれる粒子の層の番号は、親の層を引き継ぐ（元は0）。
- 境界: 元と同じ `boundary(z,w,region,faces)` を使う。面を越えたら層の番号を更新し、次のステップから新しい密度を使う。

### 1-3. 線源と採点

- Fanoの線源: 質量厚さ `m=u1*M_total`（`M_total=m_faces[-1]`）で層と深さを決め、向きは等方（`uz=2*u2-1`、方位角 `2π*u3`）。乱数はこの順に3つ引く。x=y=0。陽電子なら元の陽電子の線源と同じ初期化（静止質量の扱い、飛行中の消滅の残りの量）にする。
- 質量厚さの採点: 沈着のたび（元の `tracked_segment`・`tracked_local` を呼ぶ箇所すべて）に、質量厚さの座標で同じ按分をする配列 `mass_batches (100, nmass)`、`nmass=round(M_total/mass_bin)`。ステップは必ず1つの層の中なので、質量厚さの始点と終点で直線按分すればよい。元の深さの採点（`dz=0.2`、`0.05` cm）は、層を指定したときは行わない（厚さが区切りの倍数にならないため）。層を指定しないときは元どおり行う。
- 追加の出力（元の出力の後ろに足す。元の順序は変えない）: `mass_batches`、`history_mass`（`record_histories` のとき `(n, nmass)`、それ以外は `(0, nmass)`）、`mass_ledger`（履歴ごとに、質量厚さの採点の和と `dep` の差が入射の 1e-9 を超えた回数）、`path_total`（荷電粒子のステップの長さ×密度の総和 [g/cm²]。P4cで使う）。

## 2. 体系（固定）

名目の飛程 `R`（ESTARの飛程を切り上げた値）: 0.1 MeV → 0.0144、1 MeV → 0.44、10 MeV → 5.0 g/cm²。区切り `mass_bin = R/40`。

| 体系 | 層の質量厚さ（R単位） | 密度の比 |
|---|---|---|
| H（一様） | A と同じ面、または B と同じ面 | すべて 1 |
| A | 2, 0.5, 0.5, 0.5, 2 | 1, 1/2, 2, 1/4, 1 |
| B | 2, 0.5, 1/40, 0.5, 2 | 1, 1, 1/1024, 1, 1 |

- 幾何学的な厚さ = 質量厚さ ÷ 密度。両端の 2R は余白（線源は置くが判定しない）。
- 判定する量（A3）: 体系A・Bとも、内側の3つの層それぞれの線量。体系Bの中央は1区切りだけの薄い気体の層。3つのエネルギーで計18個。
- 期待値: 層の沈着エネルギー = `N × T0 × (層の質量厚さ / M_total)`（`brems_mode=1`、電子の線源。エネルギーは外へ出ないので、端の影響が届かない範囲では厳密）。
- 設定: 骨格は P3b-3 の試作と同じ（`fe=0.05`、`k=0.025`、`run_p3s.inputs('elsepa')`、`run_p3s.rule_kwargs('own')`、`annihilate_in_flight=True`）。判定は `brems_mode=1`。`score_kerma=False`、`score_pair=False`。10 MeVは `elsepa` の上限（10 MeV）ちょうどである。上限で拒否される場合は 9 MeV に変え、`R` はそのまま 5.0 とする（実装時に確かめ、どちらにしたかを結果に書く）。

## 3. 検査と判定（すべて事前に固定。乱数の種も固定）

乱数の種: A1 20291780、A2 20291781、A3試し 20291782、A3本番 20291783、A4 20291784、A0・報告 20291785。エネルギー・体系ごとに、種に `1000*(エネルギーの番号 0,1,2) + 100*(体系の番号 H=0, A=1, B=2)` を足す。

- **A0 余白の確認（決定的）**: 核と同じ式で、硬衝突・制動放射の離散事象が1度も起きない場合の最大の経路の長さ（`∫dT/S_restricted`、`T0` から10 keVまで、密度1）を数値積分で求める。3つのエネルギーで 2R 未満であること。満たさなければ止めて報告（体系は変えない）。
- **A1 元の核との一致**: 層を指定しないとき、次の3条件で `photon_transport_p3b.run_coupled` と全出力（元の出力の分）がバイト単位で一致: (i) Mohanのスペクトルが無い環境でも動くよう単色 6 MeV の光子・平板30 cm・2,000履歴、(ii) `charged_source_T=2`・`brems_mode=2`・2,000履歴、(iii) `positron_source_T=5`・2,000履歴。加えて、`layer_faces=[0,30]`・`layer_rho=[1]` を明示した場合に、沈着の総量 `totals` と `counts` が (i)〜(iii) と一致。
- **A2 履歴ごとの一致**: `history_rng=True`・`record_histories=True`、各2万履歴、Fanoの電子の線源。体系Aと「Aと同じ面を持つH」、体系Bと「Bと同じ面を持つH」を、3つのエネルギー、`brems_mode` 1 と 2 で比べる（計12組）。履歴ごとに、質量厚さの区切りの沈着の差の絶対値の最大が、その履歴の入射エネルギーの 1e-9 以内なら「一致」。判定: 各組で一致した履歴が 19,980 以上（99.9%）、かつ一致した履歴だけの総和の差が総量の 1e-9 以内。一致しなかった履歴は番号と差の最大を最大20個記録する。
- **A3 Fano試験**: 2節の18個。層の沈着エネルギー（100バッチ）について、`(平均 − 期待値)/期待値` の絶対値が 1% 以内、かつそのSEMが 1/3% 以内なら合格。SEMが超えたら「統計不足」、SEMは満たし差が超えたら「不合格」。分類の順は、SEM超過 → 統計不足、その後に差。
  - 試し計算: 各条件20万履歴。18個それぞれのSEMから `N_need = 200000 × (SEM/(1/3%))²` を求め、エネルギー・体系ごとに最大を取り、1.5倍して20万の倍数に切り上げる（最低20万）。1条件で2,000万履歴を超える場合は本番に進まずユーザーに相談する。
  - 試し計算の後、`lock_p4a.json` に粒子数・種・規則・新しいファイルのハッシュを書く。本番と解析は、このファイルとハッシュが一致するときだけ動く。試し計算の結果は判定に使わない（表には載せる）。
  - 全履歴で `violations`・`mass_ledger` が0、`counts[5]`・`counts[6]`（打ち切り）が0であること。0でなければその条件は「判定できない」。
- **A4 感度の確認**（体系A、1 MeV、`brems_mode=1`）: (a) `fault=1` でA2と同じ比較（2万履歴）をし、一致した履歴が 19,980 未満になること。(b) `fault=2` でA3と同じ計算（20万履歴）をし、内側の3層のうち少なくとも1つで、差の絶対値が1%を超え、かつSEMの3倍を超えること。(a)(b) のどちらかが成り立たなければ、A3の本番に進まず報告する。
- **報告のみ**: (1) 余白を2倍（4R）にした体系Aの1 MeV・20万履歴での内側3層の値。(2) `brems_mode=2` での内側3層の線量の相互の差（期待値との差は出さない）。(3) 陽電子の線源（1 MeV、体系A、`brems_mode=2`）での層ごとの沈着。(4) 区切りごとの `沈着/期待値` の図（体系A・B、3エネルギー）。(5) 計算時間。

実行の順: 試験 → A0 → A1 → A4 → A2 → A3試し → 鍵 → A3本番 → 解析。A1が通らなければ以降に進まない。A2・A3が不合格でも、許容値・体系・種を変えて再計算しない。

## 詳細レビューの反映（本文と食い違う場合は、この節が優先する）

1. **A2・A4(a)の種**: 比較する組の両側で同じ種を使う。組の種 = `20291781 + 1000*(エネルギーの番号) + 100*(組の番号: A–H_A=1, B–H_B=2) + 10*(brems_mode−1)`。A4(a)は `20291784`（正常なH_Aと `fault=1` のAの両方に同じ種）。A1は旧核と新核に同じ種。
2. **Hの面**: 一様な体系は2つあり、`H_A` は面の深さ [cm] を体系Aの質量厚さの面と同じ数値にし、`H_B` は体系Bのそれにする。密度はすべて1。総質量厚さは A・H_A が 5.5R、B・H_B が 5.025R。
3. **旧採点**: 層を指定したとき（`layer_faces` が `None` でないとき）は、旧い深さの採点（`hs`・`fine`・`pair_score`・カーマ）と、その誤差の判定（`violations[1]`・`[2]`）を行わない。収支の `violations[0]` は残す。質量厚さの採点は `mass_ledger` で検査する。`run_coupled` の `expand_regions` による「厚さが区切りの倍数か」の検査も、層を指定したときは通さない。カーマの多層対応はP4aでは実装しない（層を指定したとき `score_kerma=True` は `ValueError`）。
4. **A3の統計**: バッチ `b` ごとに `r_b = E_b / ((N/100)×T0×Δm/M_total) − 1` を作り、`mean(r_b)` を差、`std(r_b, ddof=1)/sqrt(100)` をSEMとする（`N` は100の倍数であること）。同じ沈着率の合成データで `N` を変えても差とSEMが正しいことを試験する。
