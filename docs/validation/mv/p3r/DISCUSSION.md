# P3r: 制動放射の光子を運ぶ — 考察

数値は[RESULTS.md](RESULTS.md)と`analysis.json`。値は`Dref`に対する%、±はSEM。

## 1. 光子を運ぶ設定で、試作はEGS5と合うか

深部5ブロックの差は −0.04〜+0.04%（SEM 0.09〜0.13%）で、すべて1%以内。これまでの「その場に沈着」の比較（P3a・P3s）と同じ水準で、制動放射の光子の発生と輸送を足しても一致は崩れなかった。
制動放射の式は両コードで同じ（Bethe–Heitler＋遮蔽）、規格化だけが違う（EGS5は同梱の補正係数、試作はESTARへの自前の規格化）。両者の放射阻止能は0.02%で一致しているので、この結果は見込みどおりである。

## 2. 光子を運ぶと線量はどう変わったか（事前の見積もりとの突き合わせ）

| 量 | 事前の見積もり（計画2節） | 試作 | EGS5 |
|---|---|---|---|
| ピーク付近の変化 | −0.5〜−1% | −0.86 ± 0.16 | −0.82 ± 0.13 |
| 深部の変化 | 浅い側より小さい | −0.68（5〜10 cm）→ −0.09（25〜30 cm） | −0.58 → −0.06 |
| スラブ全体の沈着の変化（相対） | −0.2〜−0.5% | −0.47% | −0.38% |
| コード間の差の変化 | 0.1%未満 | 差の差は −0.16〜+0.03%（SEM 0.12〜0.17%） | — |

- **大きさ**: 制動放射として出たエネルギーは1履歴あたり約0.014 MeVで、入射エネルギー（平均2.80 MeV）の0.50%、沈着（約1.42 MeV）の約1.0%にあたる。浅い側ではこの分がほぼそのまま線量から抜ける（−0.8〜−0.9%）。見積もり（放射収率0.5〜1%）と合う。
- **深さによる違い**: 深くなるほど変化が小さくなり、20 cmより深いところではほぼ0になる。上流で生まれた光子が下流で吸収されて、その場で失った分を埋め合わせるためと考えられる。光子の減衰と二次電子の関係（荷電粒子平衡）と同じ構図で、制動放射の光子（平均で0.1〜0.2 MeV、水中の平均自由行程は約6〜7 cm）が積み上がるのに10〜20 cmかかることと整合する。
- **逃げる割合**: スラブ全体の沈着の減り（試作 0.0067 MeV/履歴、EGS5 0.0055 MeV/履歴）を発生エネルギーで割ると、試作で約48%、EGS5で約39%が外へ逃げたことになる（それぞれ±5ポイント程度の統計誤差。差は約1.3σで、有意とは言えない）。残りの約半分はスラブの中で吸収し直された。

## 3. 放射損失を離散にしただけで、ビルドアップの差は変わったか

変わらなかった。「離散・その場」−「連続」はビルドアップで −0.06 ± 0.16%、深部でも −0.08〜+0.19%で、統計の範囲で0と区別できない。計画で見積もった大きさ（0.1%程度）はこの精度では見えない。

ビルドアップでの試作の超過は、条件を変えても同じ向きに残っている:

| 条件 | 試作 − EGS5（ビルドアップ） |
|---|---|
| 連続損失・その場（P3s、採用した刻み） | +0.27 ± 0.14 |
| 離散・その場（今回） | +0.21 ± 0.15 |
| 離散・輸送（今回） | +0.39 ± 0.16 |

（上の2つは同じEGS5の計算を基準にしているので、互いに独立ではない。）
したがって、**放射損失の扱いの違い（連続か離散か、運ぶか運ばないか）は、この超過の主な原因ではない**。ユーザーの仮説（電子の扱いをEGS5に近づければ差が減る）は、刻みの規則（P3s）に続いて、放射損失についても支持されなかった。残る候補は、多重散乱の角度分布や境界の扱い、弾性散乱の断面積の違い（ELSEPAとEGS5の表）、低エネルギーの光子・電子の細部などで、まだ絞れていない。大きさは約0.3%で、深部の判定には影響しない。

## 4. 制動放射の回数と発生エネルギーの差（原因は未解明）

試作はEGS5より、回数で −0.69 ± 0.17%（約4σ）、発生エネルギーで −1.23 ± 0.39%（約3σ）少ない。発生エネルギーは計画の目安（1%）を超えた。計画は、この場合に「式・表の補間・電子のエネルギー分布」を調べると決めている。

- **式**: 原因ではない。同じ電子エネルギーで、試作の頻度の表と、EGS5の式（EGS5同梱の元素別の補正係数を実行時に読んで掛けたもの）を比べると、0.05〜10 MeVの10点で差は −0.03〜+0.07%（`supplementary/brems_gap.{py,json}`。Codexの独立な積分の「約0.06%以内」と合う）。平均の光子エネルギーの差は0.05%未満（計画1節）。試作の中では、発生の回数とエネルギーが式の期待値と一致している（G3、z = +0.2、−0.1）。
- **電子のエネルギー分布（対生成の数の差）**: 原因ではない。スペクトルの光子が最初の相互作用で対生成を起こす回数（0.0215/履歴。実測は散乱後の光子の分を含めて0.0233）と、生まれた電子・陽電子の放射収率から見積もると、対生成由来の制動放射は全体の発生エネルギーの約6%。対生成が1.4%少ないことで説明できるのは約−0.09%にとどまる（同じ補足）。
- **表の補間（EGS5側）**: 調べたが、結論は出ていない。EGS5は電子の量を、エネルギーについて区分的な直線で近似した表から引く。PEGSの入力は許容誤差1%（`EPE=0.01`）で、PEGSの出力には電子の表について「割り当てた区間数（150）では足りなかった」という警告が出ている。表そのものも読んでみたが、表の「離散事象の全断面積」は2 MeVより下でMøller散乱の頻度と合わず（0.1 MeVで10.2対19.2 /cm。10 MeVでは8.7421対8.7418で合う）、単純な断面積ではない量が入っているらしく、制動放射の頻度として読み解けなかった。10 MeVに限れば、表の制動放射の割合から出した頻度は式より1.2%高い。この向きは実測の差（試作が少ない）と合うが、1点だけなので根拠としては弱い。
- **結論**: 原因は未解明。式と対生成は外れ、EGS5の表の近似が残る候補。確かめるには、EGS5の利用者コードで電子のエネルギーごとに制動放射の回数を数えて式と比べるのが直接的（未実施）。
- **線量への影響**: 発生エネルギーは入射の0.50%なので、その1.2%は入射の0.006%。深部の線量の比較（SEM 0.1%）には見えない大きさで、R1・R2の判定は変わらない。

## 5. 放射収率（G7）がCSDAの値より3〜4%高いこと

無限の水で、2・5・10 MeVの電子の放射収率は、ESTARの阻止能の比を積分した値（CSDA近似）より3.4〜3.8%高かった。両者は同じ量ではない。CSDAの値は「平均のエネルギー損失に沿って減速する1個の電子」の収率で、確率的な輸送では、(a) Møller散乱で生まれた二次電子も放射する、(b) エネルギー損失のゆらぎがある（収率はエネルギーに対して下に凸なので、ゆらぎは平均の収率を上げる）。どちらも収率を上げる向きに働く。大きさの内訳は分けていない。計画ではこの検査を異常の検出（10%超）に限っており、その範囲では問題がない。

## 6. 計算時間

本計算では、試作は連続損失の225 µs/履歴（P3s）から、離散・その場で308 µs、離散・輸送で317 µsになった。EGS5は78 µsで、試作はEGS5の約4.1倍になった。計画0.3節の「計算時間への影響は小さい見込み」は外れた。

内訳を、同じ5万履歴（Mohanスペクトル、seed 777、1本だけで実行）で測った:

| 条件 | µs/履歴 |
|---|---|
| P3sの輸送 | 204 |
| 新しい輸送、離散事象を切る（結果はP3sと完全一致） | 261 |
| 新しい輸送、離散・その場 | 301 |
| 新しい輸送、離散・輸送 | 309 |

- 増えた約105 µsのうち、**約57 µsは離散事象を切っても残る**。物理の結果は1ビットも変わらないのに遅いので、写した輸送ループの作り（ステップごとに事象の順序を決めるための配列を作る、係数の更新で阻止能の補間を重ねて呼ぶ、など）による無駄と考えられる。どの処理かは切り分けていない。
- 約40 µsは離散事象を入れたことによる分（表の参照と、事象で区切られてステップが増える分）。
- 光子を運ぶこと自体は約8 µsで、小さい。
- 速度の改善は今回の対象外。離散事象を切った状態でP3sと同じ速さに戻すことが最初の目標になる（結果が完全一致なので確かめやすい）。GPU向けの作り直しの前に片付ける項目として残す。

**追記（2026-10-12、P3t）**: 上の「写した輸送ループの無駄」を測って切り分け、外した。原因は2つ: (a) 戻り値を使っていない事象順序の関数をステップごとに呼び、そのたびに配列を作っていた（23〜28 µs）、(b) 阻止能の関数の中と外で制動放射の表を2回引いていた（36〜57 µs）。この2つを外した新しいモジュール（`photon_transport_p3t.py`）は、結果がP3rとバイト単位で一致し、離散事象を切るとP3sと同じ201 µs、光子を運ぶ設定で228 µs/履歴（P3rは301 µs）。この節の `photon_transport_p3r.py` は書き換えていない。詳細は [P3tの結果](../p3t/RESULTS.md)。

## 7. この結果が言えないこと

- 広い平行ビームと30 cmの水スラブでの比較である。照射野のあるPDD/OCR（P3b）ではない。
- EGS5と同じ式を使っているので、**式そのものの正しさ**（特に0.2 MeV未満の電子で光子エネルギーの分布の形が不正確なこと、放出角を1つの値に固定していること）はこの比較では確かめられない。
- 水だけの確認である。原子番号の大きい物質では制動放射の寄与が大きく、式の近似の影響も大きくなる。
