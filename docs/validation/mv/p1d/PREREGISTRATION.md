## 目的

P1cでは、採用していた刻み（`K1_max` = 0.05）で、1刻みあとの横方向の広がりが逐次散乱の参照より約2%小さく、許容2%の閾値の上にあった。
この計画は、多重散乱の刻みの上限を半分（`K1_max` = 0.025）にした条件を新しい採用条件として、健全性検査とEGS5比較を最初からやり直す。

- **問いF**: `K1_max` = 0.025で、健全性検査がすべて通り、2 MeVのEGS5比較（K6の規則）を満たすか。`dcslib`（EGS5と同じ散乱データ、研究専用の対照）と`mf`（解析式）のそれぞれで答える。

### この追試の位置づけ（結果を見たあとの条件変更であることの開示）

- 刻みを変える判断は、P1cの結果を見たあとに行った。事前登録の趣旨を損なわないよう、次を守る。
  - 刻みの選び方の根拠は、EGS5に依存しない検査（K9(i)。逐次散乱の参照との比較）だけである。EGS5との一致を良くするために選んだのではない。
  - P1の計画にある規則「K8を満たさない場合は刻みを半分ずつ細かくする。自己収束による選定であり、EGS5に合わせる調整ではない」と同じ考え方を、K9(i)に当てはめる。
  - 半分にする回数は1回と決め、この計画で固定する。結果が思わしくなくても、さらに細かい刻みをこの計画の中で試さない。
  - P1・P1b・P1cの判定と記録は書き換えない。P1bの`dcslib`の合格（`K1_max` = 0.05）も、P1cの未判定も、そのまま残す。
- 計画を書く時点で分かっていること（隠さない）:
  - `K1_max` = 0.025でのK9(i)の値は、P1b・P1cで計算済みである（前提事実2）。
  - P1b・P1cのK8で、`K1_max` = 0.025の2 MeVの計算が各100万履歴で保存されている（`ms_half`）。P1cでは、基準の刻みとの線量の差は0.49% `Dref`だった。
  - `mf`・`K1_max` = 0.05の2 MeVの計算とEGS5の線量の最大差（0.94% `Dref`）は、Claudeが判定の外で計算して既に知っている（CLAUDE.mdに記載）。`dcslib`・`K1_max` = 0.05の値（0.54%）はP1bの正式な結果である。
  - 保存済みの`ms_half`（`K1_max` = 0.025）とEGS5との比較は、ClaudeもCodexのP1c実装も行っていないと申告する（P1cでは停止規則により未評価で、成果物にその値はない）。これは申告であり、ファイルから証明できる事実ではない。この計画でも、判定には保存済みの`ms_half`を使わず、別の固定seedで新しく計算する。保存済みの`ms_half`は、新しい計算との整合の確認（統計の範囲で一致するか）にだけ使う。

## 設計上の決定

- 新しい採用条件: `K1_max` = 0.025、`f_E` = 0.05（変えない）。採用の候補はこの1つだけである。`K1_max` = 0.0125はK8（刻みをさらに半分にしたときの自己収束）の検査のためだけに計算し、採用や、EGS5との比較には使わない。
- 変えるのは実行時の引数（刻みとseed）だけである。既存の`run_transport.py`の`execute`はseedが固定で引数がないので、P1d専用の入口から、seedを引数に持つ輸送関数（`transport.run`）と逐次散乱の参照（`reference.fixed`）を直接呼ぶ。既存のファイルは編集しない。輸送の状態機械、損失モデル、採点規則、解析関数、backendのコードと表、EGS5の基準runは変えない。EGS5の再計算はしない。
- 対象のbackendは`dcslib`と`mf`。`rutherford`と`eedl`は対象外。
- 出力は`docs/validation/mv/p1d/`に書く。P1〜P1cのディレクトリへ書かない。

## 事前登録する判定ルール

結果を見てから変えない。P1〜P1cの共通の定義（基準線量、R50、Rp、評価bin、統計の要求、ブートストラップ）をそのまま使う。実装者は計算の前に、この節を`docs/validation/mv/p1d/PREREGISTRATION.md`に写して固定する。

| # | 項目 | 条件 |
|---|---|---|
| R0 | 回帰と凍結 | 開始時に、次のSHA256を`initial_hashes.json`に保存する: `prototypes/mv_electron/`の既存の全`.py`、`docs/validation/mv/p1`・`p1b`・`p1c`の全ファイル（Gitで追跡していないもの、`.gitignore`で除外した`.npz`を含む）、使用するGS表とEGS5の基準データ。`PREREGISTRATION.md`とP1dの判定スクリプトも、本計算の前にハッシュを固定する。終了時に、これらがすべて開始時と一致する。加えて、`dcslib`と`mf`の10⁴履歴のrun（`K1_max` = 0.05と0.025のそれぞれ、seed 20261007）が、P1dのスクリプトを加える前後で完全に一致する |
| R1 | K9(i) | 2 MeV、損失なし、道のり0.05 cmと0.2 cm、`K` = 0.025の2条件を、各backendで上の表の条件で計算し直す（`K` = 0.05の条件は判定に含めない）。横変位の二乗平均と深さ方向の変位の平均が、同じbackendの逐次散乱の参照と相対2%以内。差のSEMが相対0.5%以下であること（満たさなければ「統計不足」とし、合格にも不合格にもしない）。保存済みの値（前提事実2）との整合を記録する |
| R2 | 輸送の健全性 | 新しい採用条件を基準にして、P1cのN5と同じ検査を行う: K5、K5b、K7（境界の分割と位置ずらし）、K8（`K1_max`を0.0125に、`f_E`を0.025に、別々に半分にする。前提事実4の規則）、K9(ii)（`K1_max` = 0.025）。条件は上の表のとおり。K5bは各backendの実際の輸送用の表で全ケースを実行する |
| R3 | 2 MeVのEGS5比較 | P1のK6と同じ条件・同じ基準run・同じ許容幅。試作側は`K1_max` = 0.025、100万履歴、新しい固定seed |
| R4 | 10 MeVのEGS5比較（参考） | 差を記録する。合否に使わない |

R1とR2が満たされないbackendでは、R3を判定しない（P1cと同じ停止規則）。

各項目の状態は「合格」「不合格」「統計不足」「未評価」の4つに分けて書く。「統計不足」と「未評価」では、物理的な未達を主張しない。

### 記録する補助指標（合否に使わない）

- 各backendで、`K1_max` = 0.05（P1b・P1cの保存データ）と0.025の、EGS5に対する線量の最大差、R50の差、Rpの差、後方散乱のエネルギー割合を並べる。`mf`・`K1_max` = 0.05の値は記録としてだけ載せる（P1cの未判定は変えない。最大差は既に知られている）。
- 残差の低減率を2種類、式を固定して記録する。評価binの集合`M`と`D`はP1bと同じ定義。(i) P1に対して: `r_P1 = 1 − d_new/d_P1`、`d_P1`はP1（遮蔽Rutherford、`K1_max` = 0.05）の保存済みrun。(ii) 同じbackendの刻みに対して: `r_K = 1 − d_new/d_old`、`d_old`は同じbackendの`K1_max` = 0.05の保存済みrun。`d_new`はP1dの`base_2`。点推定とブートストラップ（batch単位1000回、seed 20261008、同じEGS5の再標本を両方に使う、百分位法の95%区間）は、同じ比較元を使う。
- `mf`と`dcslib`の深さ線量の差（最大差とその深さ、R50より深いbinの差）。
- 新しい計算と保存済みの`ms_half`の深さ線量の差と、その合成SEMに対する比。
- 計算時間（P1bと同じ方法、`K1_max` = 0.025での単価）。

### 結論の書き方

- R0〜R3がすべて満たされたbackendについて「2 MeV・水・指定条件（`K1_max` = 0.025）で電子輸送の試作が成立」と書き、散乱データの種類（`dcslib`は研究専用の対照、`mf`は解析式で低Z限定）を必ず添える。
- 結論のすぐ後に、「刻みはP1cの結果を見たあとに変えた。選定の根拠はEGS5に依存しない検査である」と書く。
- R1が満たされない場合は「刻みを半分にしても横方向の広がりの検査を満たせなかった」と書いて止める。さらに細かい刻みは別の計画にする。
- K9(i)のずれの原因（有限の刻みによる偏り）は、`K`を半分にすると差が縮むという事実と分けて、仮説として書く。

## 不一致のときの進め方

- 合わせるための調整（係数、倍率、カットオフ、許容幅、さらに細かい刻み）はしない。
- R0が満たせない場合は停止する。
- 原因の説明は、確かめた事実と仮説を分けて書く。
