## 固定した収支の実装上の定義

E_in = E_dep + E_escape + E_unprocessed + ΔE_rest。
残差 r = (E_in − E_dep − E_escape − E_unprocessed − ΔE_rest)/E_in。
|r| ≤ 1e−4を判定に使う。光子は全エネルギー、脱出する荷電粒子は運動エネルギーを計上する。
生成された電子・陽電子の静止質量の保存と、媒質電子との消滅による媒質の静止質量減少を正味で計上し、二重計上しない。
カットオフ沈着はEGS5のEDEPを使用する。陽電子の停止後の消滅光子2mc²を沈着として再加算しない。
未処理・異常終了履歴を別欄とする。追跡できない収支項は0と仮定せず判定不能とする。
