# P2 採用モデルと根拠

単色光子1.25/2/6/10 MeV、水rho=1 g/cm³、横方向無限、厚さ30 cm。
横方向の全沈着を深さだけで採点する。MeVからJへの変換はscipy.constantsの
電子ボルト値から取り、Edep/(N rho dz) × MeV_J ×1000 = Gy·cm²。

XCOM配布ソースの版は3.1、1999-06-23。ソースと生成表のハッシュは
photon_generation.json。要求エネルギーを別に保存する。印刷列は格子に使わない。
水の質量分率はATWTS.DATのH/O原子量からH2Oとして計算した値を使う。
電子輸送の数密度はP1の固定値を維持する。この僅かな組成定義の差を隠さない。

実ファイルの確認:

- XCOM.f:37: `DATA EPAIR1/1.022007E+06/,EPAIR2/2.044014E+06/` (eV)。
- XCOM.f:231–237: `LOG(PAIRAT(M)/(TERM**3))`、電子場も同式。
- XCOM.f:280–289: Eが閾値を超えるときだけ補間し、`(TERM**3)*EXP(RES)`で復元。
- XCOM.f:291–308: 光電はlog-log、吸収端別の処理。H/Oの端はP2下限1 keVより下。
- P0旧表は閾値の両側の要求値を同じ印刷値に丸める。要求列はcheck_photon_data.pyに残る。
  P2ではこの列の紛失を防ぐ。P0の合成/直接比較はphoton_check.jsonにある。
- egs5_hatch.f:695: `pcut(jr) = max(pcut(jr),ap(md))`。
- egs5_photon.f:321–329: cutoffなら輸送前に終了。
- pegs5.f:1342–1362: IUNRST=4はMøller/Bhabhaだけを離散の荷電過程とし、消滅を除外。
- pegs5.f:5027–5028,5051–5052: IUNRST=4では制限衝突＋非制限放射阻止能。
- pegs5.f:1141–1206: DIFFERが材質の遮蔽パラメータを生成する。
  pair_parameters.jsonは既存H2O/rho=1のPEGS輸送データを機械読取したもの。
  APの値はDIFFERに入らず、ここでは線量出力を参照しない。

対生成のエネルギー分配:

- egs5_pair.f:35–37: E<=2.1 MeVなら小さい方の全エネルギーは
  `RM + rnnow*(eig/2. - RM)` (一様)。
- 同:39–45: 2.1<E<50 MeVではlvx=1,lvl0=0。P2の全エネルギーはこの範囲以下。
- 同:48–77: br=e_small/E, br∈[m/E,1/2]。一様成分の確率bpar、
  12(br−1/2)^2成分の確率1−bpar。半区間の密度は2と24(br−1/2)^2。
  del=1/[E br(1−br)]、del<delposを要求、delta=delcm del。
  各成分の受容係数はdelta<1でDL1+delta(DL2+delta DL3)、それ以外で
  DL4+DL5 log(delta+DL6)。高次の式や分配の選び直しは行わない。
- 同:200–210: 既定IPRDST=0の極角theta=m/E、方位角は一様で、2粒子の横方向は反対。
- 同:212–220: 正負の電荷を等確率で割り当てる。

Comptonは自由電子Klein–Nishina、全断面積も解析式。
q=E'/E、x=E/m、q∈[1/(1+2x),1]。
`dσ/dq = π r_e²/x [q+A+B/q+C/q²]`、A=2/x+1/x²、B=1−2/x−2/x²、C=1/x²。
μtrのCompton項はこの式×(1−q)の閉じた積分:
F(q)=q²/2−q³/3+A(q−q²/2)+B(log q−q)+C(−1/q−log q)。
σtr=πr_e²/x [F(1)−F(q_min)]。原子あたり電子数密度を掛ける。
光電転移率1、対生成転移率1−2m/E。

NIST μen/ρ はbundled water.csvからlog-log補間する診断量。
[NIST section 3](https://physics.nist.gov/PhysRefData/XrayMassCoef/chap3.html)の
式7–13によるμen=(1−g)μtr。gは全過程で作られた荷電粒子の初期運動エネルギーで
重みづけた放射収率。NISTは制動放射、飛行中消滅、荷電粒子による蛍光、
stragglingとknock-onを含む。P2ではこの係数から省略寄与を個別数値分離できない。
Q4では採用モデルの光電・Compton・対生成のμtr各成分とNISTとの比を記録する。
束縛と蛍光、三重項反跳を省くため、NISTとの比で合否を決めない。

制動放射の参照側局所処理:

- egs5_brems.f:136–149: 小さいエネルギーの粒子が上に来る。光子が常にNPではない。
- IUNRST=0、IBRSPL=0、IAUSFL(8)=1。IARG=7で上2粒子のIQ=0だけに
  専用LATCH、DNEAR=0を設定。HOWFARでIDISC=1、IARG=3でEDEP×WTを採点。
  IARG=7では沈着を採点しない。
- IUNRST=4は非標準。PEGS User Manual pp.27–28に輸送用データ生成で使わないよう明記。
  自己点検結果をegs5/各ケースのsummary.json、阻止能をt5_stopping_selfcheck.jsonに保存する。
  旧自己点検と修正コードの新自己点検を分け、利用可否はt5_selfcheck_d2.jsonに記録する。

既定フラグ（要求値; 実効値と検査結果は各egs5ケースのsummary.jsonに保存）:
IBOUND=INCOH=ICPROF=INCOHR=IPROFR=IRAYL=IRAYLR=IEDGFL=IAUGER=0、
IPRDST=0、IBRSPL=0、AP=PCUT=0.01 MeV、AE=ECUT=0.521 MeV（C2）。

### 陽電子

- 陽電子は、阻止能・多重散乱（電子用のデータ）・硬い衝突（Møller）を電子と同じモデルで運ぶ。下限に達したら、残りの運動エネルギーをその場に沈着し、静止消滅で511 keVの光子2個を反対方向・等方に出す。飛行中の消滅は実装しない。
- EGS5は陽電子に専用の弾性散乱データとBhabha散乱、飛行中の消滅を使う。これは設定でそろえられない。したがって、対生成がほとんど起きない1.25 MeVと2 MeVを「光子側と電子輸送の連成の検査」、6 MeVと10 MeVを「陽電子のモデル差を含む連成の比較」と呼び分け、結論でも分ける。
- 試作では、対生成に由来する沈着（陽電子とその相手の電子、消滅光子の子孫）を別に集計する。

### 制動放射

- 試作: 明示的な光子を作らない。放射損失は連続損失で、局所に沈着する（P1と同じ）。
- EGS5の基準（主）: 標準の設定（`IUNRST=0`、`AP` = `PCUT` = 10 keV）で計算し、ユーザーコードで、制動放射で生まれた光子のエネルギーを発生点に沈着させて捨てる。放射損失は確率的になるので、試作の連続損失とは同じではない。手順（Codexレビューがソースで確認。実行による確認は未）: `IBRSPL=0`を固定する。`IAUSFL(8)=1`にして`AUSGAB(IARG=7)`（制動放射の直後）で、スタックの上2つのうち`IQ=0`の生成された光子だけに専用の`LATCH`を付け、`DNEAR=0`にする（BREMSはエネルギーの低い粒子を上に置くので、無条件に`NP=NP-1`とすると荷電粒子を捨てることがある）。`HOWFAR`でその光子を`IDISC=1`にし、`IARG=3`で`EDEP×WT`を発生点に採点する。`IARG=7`では採点しない（二重計上を避ける）。一次光子、Compton散乱光子、消滅光子には印を付けない。
- EGS5の基準（感度）: `IUNRST=4`（放射損失が連続）でも計算する。非標準の設定なので、使う前に、阻止能、収支、消滅の扱いを自己点検して記録する。
- 主と感度の差は、放射損失の扱いの差と、飛行中の消滅の有無の差の両方を含む。これをエネルギーごとに「基準側のモデルの幅」として記録する。この幅がどこかの評価binで1% `Dref`を超えたエネルギーでは、Q6の状態を合否でなく「基準の幅が大きく判定を保留」とする。

### 採点と統計

- 深さのbinは2 mm。これと別に、0.5 mmの採点を全深さ（30 cm）に持つ。
- 不確かさは一次光子の履歴単位（全子孫をまとめる）のbatch統計。batchは100個。履歴ごとのledgerは保存しない（履歴数が大きいため）。収支は履歴ごとに検査し、最大残差と違反の数だけを保存する。
- 補助量: 採用モデルの`μ_tr`による全カーマ（光子の飛跡長）と、NISTの`μen/ρ`による衝突カーマを、同じbinで採点する。後者は「省いた物理と違う係数による診断量」と明記する。

実効値に関する注意: 自己点検はP1のPEGS入力を機械的に拡張しており、AE=0.521 MeVが残る。
C2でECUT要求値も0.521 MeVとし、HATCHのAEとのmaxによる実効値も0.521 MeVである。
したがって荷電粒子下限は厳密10 keVより約1 eV高い。AP=PCUT=0.01 MeVは厳密に満たす。
各summary.jsonにこの実効値を保存している。追補1で差を受け入れ、厳密10 keVへの統一は行わない。
線量結果を合わせるためのカットオフ調整は行っていない。Q6は未評価。

収支の静止質量の定義: 試作では対生成のたびDelta_restに+2m、静止消滅で−2m。
脱出/未処理の荷電粒子エネルギーは運動エネルギーを保存する。このrest勘定は、
生成された電子/陽電子の静止質量と、消滅相手の物質電子の静止質量の純変化である。
EGS5は脱出する陽電子をE_total+m (=T+2m)としてdiscardするので、
同じ静止質量予算をescape側に含む（egs5_electr.f:659–663）。線量の定義は共通。
