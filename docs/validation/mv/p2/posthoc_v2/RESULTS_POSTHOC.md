# P2 保存結果の基準v2による事後解析

これは探索的な事後解析である。P2の事前登録の正式な判定は計画0.3のまま変更しない。Q0〜Q4は旧判定を維持、Q5は記録、Q6は判定保留、Q7は統計不足である。Q6の内訳はdcslib・elsepaの全エネルギーが未評価、mfの1.25・6・10 MeVが判定保留、2 MeVが未評価。

基準v2は文献調査と保存結果の探索的解析の両方を踏まえた再設計である。P2の計画を書いたClaudeはコード間比較の先行報告を調べずに基準を決めており、計画時のリサーチ不足を経緯として記録する。計画0.4の試算と骨子レビューの値を見たあとに基準を決めた。深部は通りそうでビルドアップは境界に近いと分かったあとの選択であり、結果から独立した変更とは主張しない。将来の新規計算では計算前に固定する。TG-105の表I等は比較結果の要約であり、5 cmブロック・深部だけ・1%という一式の判定法を規定していない。旧基準の全項目が誤りだったとは主張しない。

判定する量は固定した深部ブロックの平均線量の差だけであり、ビルドアップを含むP2の元の問いより狭い。ここでいう系統差は期待線量のブロック平均のコード間差である。ブロック内部の打ち消し合い（2 cmが+2%、残りが−1.33%など）は検出できない。差は固定したDrefに対する割合で、倍率で合わせず、Drefの推定誤差は伝播しない。

この方式の性質: SEMがちょうど1%/3のとき、「1%以内」と出る確率は、真の差が0.5%で約93%、0.8%で約73%、1.0%で約50%、1.3%で約18%。真の差が1%をわずかに超えていても、半分近い確率で「1%以内」と出る。SEM上限の1%/3は許容の3分の1という経験則であり、文献の規定ではない。|Δ|+1.96 SEMは参考値で、判定には使わない。超える側の多重比較補正は行っていない。

表の線量差・SEM・参考値・bin最大差はすべて % Dref。±はSEM（95%区間の半幅ではない）。形の差は深部平均で規格化した曲線どうしの無次元差で、% Drefとは別の尺度である。
