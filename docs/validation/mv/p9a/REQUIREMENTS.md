# 要件: 前立腺シードを入れたままの 10 MV 7 門照射（2026-10-24 聞き取り、使用者承認済み）

| 項目 | 内容 |
|---|---|
| 目的 | 10 MV の 7 門照射で、近くに並んだ複数のシードが線量分布をどう乱すか（上流側の増加・下流側の影・影の重なり）を見る。組織の線量は評価しない |
| 線源 | Mohan 10 MV、SAD 100 cm、アイソセンターは前立腺の中心、仰臥位 |
| 門 | ガントリー 0, 45, 90, 135, 225, 270, 315°（0° = 前、180° の後方門を外す）、各門の光子数は同じ |
| 照射野 | ① 矩形 7×7 cm²（アイソセンター面）② 門ごとに前立腺の投影に絞った理想的な照射野（MLC の漏れ・半影の構造は無視）。2 通りを同じ形状で計算 |
| 体 | 横 36 × 前後 24 cm の水の楕円柱（代表値（未確認）: 骨盤の大きさの目安として Claude が提案）。水以外の組織は入れない |
| 前立腺・直腸 | 前立腺 4.5（左右）× 3.0（前後）× 3.5（頭尾）cm の楕円体（24.7 cc。320 例の中央値 24.5 cc、PMC10136498 に合わせた形。寸法の配分は代表値（未確認））。直腸は前立腺の後ろに接する直径 3 cm の円柱（代表値（未確認））。どちらも水で、評価のための領域だけ |
| シードの材質 | 1 mm × 5 mm の均一な円柱、銀 59.6%・チタン 40.4%（質量比）、密度 2.47 g/cm³。根拠: 6711 型の寸法（Carleton CLRP、Dolan et al.: 銀の棒 半径 0.250 mm × 2.80 mm、チタン管 外径 0.800 mm・壁 0.070 mm・3.75 mm、端の溶接は半径 0.4 mm の半球を中まで詰まったものとして計算）から 銀 5.77 mg・チタン 3.92 mg、これを 1×5 mm（0.00393 cm³）に均した。密度 銀 10.50・チタン 4.506 g/cm³ |
| シードの配置 | 58 本。5 mm 刻みのテンプレートの穴を市松に使う（針 19 本、針の間隔 0.71 cm）、針に沿って 0.7 cm 間隔、軸は頭尾方向。シード全体が前立腺の楕円体に入るものだけ（臨床の目安: 中央値 66 本、範囲 38〜108 本、PMC10136498） |
| 出力 | シードあり／なしの線量の比の断面図（同じ乱数・同じ形状でシードを水に置き換えた計算と比べる）、線量の断面図、シードを横切る線量の線。光子 1 個あたりの相対値、数値に SEM を添える |
| 格子 | 前立腺のまわりは細かく（0.25 mm 程度）、骨盤全体は粗く（2 mm 程度）。値と履歴数は試しの計算で測ってから計画に書く |
| 照合 | 段階①の積層（水–シード相当の板–水）で EGS5 と照合。3 次元の 7 門は EGS5 と照合しない（水だけの場合に P3b-3・P7 の 1 門を再現して形状を確かめる） |
| 調整で外した・置き換えた項目 | 強度変調（本物の IMRT）は入れない → 3D-CRT 相当の分布。人体形状 → 水の楕円柱。シードの内部構造 → 均一な混合物。今の治療領域の入口（SSD 100・10×10・水 30 cm の 1 門、積層の核は z 方向だけ、材質は水・肺・骨・鉛）では回らない → 新しい開発段階で作る |
| 進め方 | ① チタンと銀の材質を追加し、積層の核で「水–シード相当の板–水」を EGS5 と照合 → ② 3 次元の形状と横方向の輸送 → ③ 回した 7 門の線源（矩形と前立腺形）と 3 次元の格子 → 本計算。各段階に計画と Codex のレビュー |

出典: [Carleton CLRP 6711](https://physics.carleton.ca/clrp/node/27)、[PMC10136498](https://pmc.ncbi.nlm.nih.gov/articles/PMC10136498/)
