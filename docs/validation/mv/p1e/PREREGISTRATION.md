# P1e PREREGISTRATION

固定時点: 実装前、生成前、本計算前。判定ルールは承認済みP1e計画の以下の原文に従う。

## 設計上の決定

### 生成

- 取得: 前提事実1のURLから取得し、SHA256を照合する。一致しなければ停止する。取得物、ビルドの生成物、実行結果は、リポジトリの外の作業用の場所（既定は`~/.cache/chatcarlo/elsepa/`、環境変数で変更可）に置く。リポジトリには、取得・ビルド・実行・変換のスクリプトと、ハッシュの一覧だけを置く。
- ELSEPAのソースは変更しない。入力ファイルだけを作る。
- 対象: Z = 1と8。電子と陽電子。
- ポテンシャルの選択（結果を見て変えない）: 自由原子（`MUFFIN=0`）、Fermiの核電荷分布（`MNUCL=3`）、Dirac–Fockの電子密度（`MELEC=4`）、電子の交換はFurness–McCarthy（`MEXCH=1`。陽電子は0）、相関・分極なし（`MCPOL=0`）、吸収なし（`MABS=0`）。前提事実5のEGS5の説明と同じ組み合わせであり、「公表されている標準的な作り方に合わせる」ことが理由である。`dcslib`との一致を良くするために選び直さない。
- 高エネルギーの扱い（`IHEF`）は、プログラムの既定（1）とする。前提事実4のとおり、水素は20.1 keV、酸素は160.8 keVより上で因子分解に切り替わり、そこでは交換のポテンシャルが無効になる。前提事実6の試行（`IHEF=0`）とは違うので、0.01〜10 MeVで両者の差を記録する。
- 選択の根拠の区別: 電子密度（Dirac–Fock）、核電荷分布（Fermi）、電子の交換（Furness–McCarthy）は、EGS5の説明と共通であることを確認した選択である。`MCPOL=0`、`MABS=0`、`IHEF=1`、陽電子の`MEXCH=0`は、EGS5の作り方が確認できないので、今回独自に固定した選択である（自由原子の高エネルギーの弾性散乱として標準的で、プログラムの既定に沿う）。
- 実行の規則: 1つのケース（原子番号・電荷・エネルギーの組）ごとに、空の作業ディレクトリで実行する。入力は全キーワードを明示して書く。出力から、原子番号・電荷・エネルギー・有効になったモデル・行数（606）・角度の両端を読み取り、要求と照合する。古い出力を読まない。
- エネルギー格子: 1 keV〜100 MeVの対数等間隔、1桁あたり16点（81点）に、検査で使う0.01、0.02、0.1、1、2、10 MeVが格子点になるよう必要な点を加える。`dcslib`の格子には合わせない。補間誤差は中間点で検査する（S2）。
- 角度格子はELSEPAの出力（606点）をそのまま使う。
- 水の有効DCSの作り方はP1bと同じ規則（元素ごとに`(Z+1)/Z`を掛けてから数密度で合成）。陽電子の表はこの計画では作って検査するだけで、輸送には使わない（P2で使う）。

### 表の形式と読み取り

- ELSEPAの出力を、エネルギー・角度・DCS・`ERROR`列の配列と、ELSEPAが印字した断面積（級数側と表の積分側を別の配列にする）、警告の文、入力のハッシュ、プログラムのハッシュを持つ1つのファイル（`.npz`）に変換する。値を丸めない。
- backend `elsepa`を試作に加える。補間の規則は`dcslib`のbackendと同じ（対数エネルギーの三次スプライン、角度方向は対数DCSの三次スプライン）にし、違うのはデータの出どころだけにする。`single_table.py`は未知のbackendをEEDLの形とみなすので、固有のエネルギー格子点を返す口を`elsepa`に持たせ、分岐を1つ加える（既存のbackendの完全一致はS0で確かめる）。
- 表の使用範囲は、S2で補間を検査した範囲（10 keV〜20 MeV）に限る。範囲外のエネルギーを要求されたら拒否する。
- 既存のbackend（`rutherford`、`dcslib`、`eedl`、`mf`）の数値を変えない。

## 事前登録する判定ルール

結果を見てから変えない。状態は「合格」「不合格」「統計不足」「未評価」に分ける。計算条件（刻み、履歴数、K7の条件、K8の規則、統計の要求、解析）はP1dの「固定する計算条件」と同じにし、seedだけ20261011（輸送とK9(i)の参照）と20261012（K9(i)の試作）に変える。やり直し、履歴の追加、seedの選び直しはしない。

### 記録する補助指標（合否に使わない）

- `elsepa`、`dcslib`、`mf`（いずれも`K1_max` = 0.025）の、EGS5に対する線量の最大差、R50の差、Rpの差、後方散乱のエネルギー割合。
- `elsepa`と`dcslib`の深さ線量の差（試作どうし。同じ輸送でデータの出どころだけが違う）。最大差、その深さ、合成SEMに対する比。
- 表の生成にかかる時間（元素・電荷ごと）、表の大きさ、輸送の単価。生成の前に代表的な条件で時間を測り、全体の見込みを記録する。生成はケース単位で保存し、中断したら同じ入力で未完了のケースだけをやり直す。

### 結論の書き方

- S1とS2が合格なら「ELSEPAによる水素・酸素の表の自前生成が、再現可能な手順で成立」と書く（問いG）。`dcslib`との一致の程度はS3の数値で書き、「一致した」「同じ」とまとめない。
- S0〜S2、S4〜S6が合格なら「2 MeV・水・指定条件で、自前生成の表による電子輸送の試作が成立」と書く（問いH）。
- 利用条件について確かめた範囲（掲載情報の表記、同梱物に別の記述がないこと）と、確かめていないこと（CC BY-NC 3.0の条文、生成した表への適用）を必ず書く。
- 陽電子の表は検査だけで、輸送では未使用と書く。

## 不一致のときの進め方

- 合わせるための調整（ポテンシャルの選択、格子、補間、倍率）はしない。
- S0またはS1が満たせない場合は停止する。S2が満たせない場合はS4以降を判定しない。
- ELSEPAが特定の入力で止まる・収束しない場合は、その入力と出力を保存して報告し、値を補わない。

結果を見てから変えない。P1〜P1cの共通の定義（基準線量、R50、Rp、評価bin、統計の要求、ブートストラップ）をそのまま使う。実装者は計算の前に、この節を`docs/validation/mv/p1d/PREREGISTRATION.md`に写して固定する。

| # | 項目 | 条件 |

| R0 | 回帰と凍結 | 開始時に、次のSHA256を`initial_hashes.json`に保存する: `prototypes/mv_electron/`の既存の全`.py`、`docs/validation/mv/p1`・`p1b`・`p1c`の全ファイル（Gitで追跡していないもの、`.gitignore`で除外した`.npz`を含む）、使用するGS表とEGS5の基準データ。`PREREGISTRATION.md`とP1dの判定スクリプトも、本計算の前にハッシュを固定する。終了時に、これらがすべて開始時と一致する。加えて、`dcslib`と`mf`の10⁴履歴のrun（`K1_max` = 0.05と0.025のそれぞれ、seed 20261007）が、P1dのスクリプトを加える前後で完全に一致する |

## P1eでの置換と手続きの固定

- 主検査のbackendはelsepa。輸送とK9(i)参照seed=20261011、K9(i)試作seed=20261012。N・刻み・K7条件は上表と同じ。dcslib/mf補助指標はP1dの保存済みK=0.025 runを読む。EGS5を再実行しない。
- S0回帰は4 backend各2 MeV、10000履歴、K=0.025、f_E=0.05、seed=20261011、平板1.2 cm、dz=0.01 cm。使用する既存GS表はp1/data/gs.npz、p1b/{dcslib,eedl}/data/gs.npz、p1c/mf/data/gs.npz。
- 凍結集合: prototypes/mv_electron/**/*.py、tests/**/*.py、docs/validation/mv/{p1,p1b,p1c,p1d}/**（全ファイル）、使用GS表、EGS5基準データ（p1/egs5内）、このPREREGISTRATION.md、今回生成する表（外部p1e/tables/*.npzとp1e/gs.npz）。計画・他文書・今回の結果ログは含めない。追加・削除も照合する。
- 最初の保全はinitial_hashes.jsonに保存。実装後・本計算前のfreeze_hashes.jsonは生成完了後に固定する。固定後にコードは変更しない。
- S2の全区間は10 keVと20 MeVを端点にした区間。20 MeVは元表の隣接点から補間し、直接検査の端点とする（生成用格子へは追加しない）。切替前後は閾値×(1±10^-6)。
- IHEF=0補助比較は0.01、0.02、0.1、1、2、10 MeVで実行。
- 生成2巡は別のケース作業ディレクトリで同じ入力を実行し、全配列を比較する。完了レシートを持つケースを再実行しない。中断ケースは同一入力で新しい空ディレクトリから再開する。
- S1失敗時は停止。S2失敗時はS4以降の計算・判定を行わない。図と補助指標の未評価も明記する。
