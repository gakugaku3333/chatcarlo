# P3b-3 考察: 照射野つきの比較で分かったこと

結果は [RESULTS_P3B3.md](RESULTS_P3B3.md)。ここでは、数値が物理的に何を意味するかを述べる。予想は計画に、計算の前に書いてある。

## 1. 深部と中央の線量: 平板と同じ水準で一致した

- 判定した8個の線量の差は −0.44〜+0.28%、各SEMは0.16〜0.27%。差をSEMで割った値は −1.6、−1.4、+1.3、+0.2、+0.1、−0.7、−1.0、+0.3 で、二乗の和は約8.0（8個）。差が0のときに期待される大きさと同じで、**この精度（約0.2%）では、系統的な差は見えない**。8個は独立ではない（直方体と側方の中央は一部が重なる）ので、この数は目安。
- 横に無限の板全体の集計（同じ計算から取れる、誤差が約3分の1の量）では、2 cmより深い6つの区間の比が −0.07〜+0.08%（SEM 0.06〜0.08%）。P3rの平板（±0.04%、SEM 約0.1%）と同じ水準で、線源を発散・有限にしても変わらなかった。
- これは予想どおり。輸送の物理はP3rと同じで、変えたのは線源と集計だけ。照射野の中央は、横から入る電子と出る電子がつり合っている（10 MVの二次電子の横の広がりは数mm、中央の領域の端4 cmは照射野の端5.25 cm以上から1 cm以上内側）ので、中央の線量は平板と同じ物理で決まる。
- 試し計算（各400万履歴）で −1.5% 前後だった2つの量は、本番で −0.2〜−0.3% になった。試し計算の差はSEMの1.7〜2.4倍で、8個のうち1〜2個がこの程度になるのは偶然で起きる範囲だった。**小さい統計で見えた差を、原因のある差として追わなかったのは正しかった**（P2bで、事後に見つけた+1.05%が5倍の統計で再現しなかったのと同じ型）。

## 2. 50%の位置: 幾何で決まり、両コードで0.002 cm以内

- 位置は 5.254、5.509、6.014 cm（試作）。点線源からの幾何（深さ d で 5×(100+d)/100）は 5.25、5.50、6.00 cm で、ずれは +0.004、+0.009、+0.014 cm。深いほど外へ動くのは、照射野の外へ出る散乱線が中央より相対的に増えて、「中央の50%」の水準が幾何の端の少し外に来るため。動きは予想した向きで、大きさは予想（200万履歴の値 6.047 ± 0.010 cm）より小さかった。200万履歴の値は本番（6.014 ± 0.003 cm）から誤差の約3.2倍離れている。**同じ200万履歴の計算（種 20291741）には、対称性の対比の z = −3.59（P3b-1のB8）もあり、誤差の3倍を超える外れが、別々の量で2つある。** この計算が今のコードと同じ結果になることは確かめた（下の4節）ので、コードの違いでは説明できない。偶然と矛盾はしないが、1回の計算に2つ重なったことは事実として記録する。
- 両コードの差は 0.0016、−0.0003、0.0018 cm（SEM 0.002〜0.004 cm）。予想（0.02 cm以下）の10分の1。**50%の位置は線源の幾何と一次線の減弱でほぼ決まり、電子の輸送の細部に鈍感な量**なので、ここが合うことは「線源と位置の受け継ぎが両コードで同じ」ことの確認として読むのがよい。P3b-1で直した「光子と二次粒子が横の位置を受け継がない」誤りが残っていれば、ここと半影の幅に出たはず。
- 電子の輸送の細部に敏感なのは半影の幅（20〜80%）。試作は 0.444、0.507、0.607 cm、EGS5は 0.451、0.514、0.617 cm で、**3つの深さとも試作が0.006〜0.010 cm狭い**。事後に求めた誤差は0.008〜0.014 cmで、1つずつはどれも誤差の内側。3つとも同じ向きだが、同じ粒子が3つの深さに寄与するので独立ではなく、差があるとは言えない。差があるとしても0.01 cm（0.1 mm）の桁で、区画の幅（0.25 cm）の25分の1。弾性散乱の断面積の違い（試作はELSEPAの表、EGS5は自前の表。P1fで水のG1に0.06%程度の差）が効くとすればこの量なので、半影を主題にするときの確認の候補として記録する。

## 3. ビルドアップ: これまでと同じ向きの小さな超過が、板全体の集計で見える

- 2×2 cmの直方体では、0–2 cmの差は +0.25 ± 0.33% で、統計の内側。
- 板全体の0–2 cmでは、沈着の比で +0.18 ± 0.08%（SEMの2.1倍）、板全体の曲線の最大に対する割合に直すと +0.13 ± 0.06%。P3a〜P3rの「試作が約+0.3% `Dref` 高い」は平行ビームの平板での値で、深さの範囲の取り方も違うので、数値をそのまま比べることはできない。言えるのは「同じ向きで、同じ桁」まで。原因は未解明のまま（P3rで、放射損失を個別の事象にしても動かなかった）。照射野にしたことで新しく生じた差ではない。
- 直方体のいちばん浅い0.5 cmは +0.85 ± 0.33%（SEMの2.6倍）。事後に切り出した区間で、深さの区切り方を選べる量なので、これだけでは何も主張しない。板全体の同じ区間を見るのが先。
- ピークの深さの差（2.25 と 2.45 cm）は、頂上が平らで1区画の誤差が曲線の傾きより大きいことによる。誤差を出していない量で、差としては読まない。

## 4. 対称性: P3b-1の不合格は、偶然と矛盾しない

- 本番の試作で、9個の対比の最大は \|z\| = 1.85。P3b-1で z = −3.59 だった対比は +0.56。23倍の統計で、偏りは見えなかった。EGS5も同じ（最大1.91）。
- P3b-1の200万履歴の計算は、速さの修正（P3b-1の追補2）より前の核で実行したもので、今のコードとのつながりは少数の基準ハッシュだけだった。今回、その計算の先頭と末尾のバッチ（各2万履歴）を今のコードで同じ種から計算し直し、21種類の配列すべてがバイト単位で一致することを確かめた。したがって、B8の値も200万履歴の50%の位置も、今のコードの値である。
- 言えるのは「中央の平均の0.8〜2.2%より大きい左右・縦横の偏りは、あれば検出できたはずで、検出されなかった」まで。P3b-1のB8の記録は不合格のまま残す（規則どおりに実行した結果であり、あとの結果で書き換えない）。

## 5. 速さ

- 試作は2プロセスで経過167 µs/履歴、EGS5は1プロセスで123 µs/履歴。1プロセスあたりでは試作が約2.7倍遅い。EGS5側が領域の集計で1.8倍遅くなったので、これまでの「約3倍」から比は少し縮んだが、試作が速くなったわけではない。

## この結果が支えること、支えないこと

- 支える: 公称10 MV・10×10 cm²・発散・水の条件で、深部のブロック平均、照射野の中央の線量、50%の位置が、EGS5と（1%、0.1 cm）の許容の内側で一致し、その精度は線量で約0.2〜0.3%、位置で約0.003 cm。
- 支えない: 半影の形の一致（幅は報告のみ）、ビルドアップの一致、他の照射野・エネルギー、空気層や実機のヘッドを含む線源、測定との一致。EGS5は研究用の参照で、公開するシステムはこれに依存しない。
- 残っている未解明: ビルドアップの約+0.2〜0.3%の超過、制動放射の数の −0.7%／エネルギーの −1.2%（P3r）。
