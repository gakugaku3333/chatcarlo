# P2b 追補1: 6 MeVのEGS5の設定間の差の調査

この調査はP2の判定も、P2bの事後解析の結果も変えない。対象の差は、12の領域の中から事後に見つけたものである。値はすべて % Dref（固定）、±はSEM。

- 再現の確認（C− − S＋、ビルドアップ）: +0.226 ± 0.126。P2の値は +1.052 ± 0.286。判定: 指定した精度の独立な再計算では差を確認できなかった。精度の目標（SEM ≤ 0.15）: 達成。
- 全沈着エネルギーの比（S＋を1として）: p2b_Splus 1.00000、p2b_Cminus 1.00118。
- 参考（P2、ビルドアップ、試作 − EGS5主）: dcslib +0.718 ± 0.290、mf +1.046 ± 0.279、elsepa +0.848 ± 0.303。

「再現」は正の向きの差を確認したという意味で、P2の値の大きさ（約1.05%）の再現を検定したものではない。2つの寄与の判定はそれぞれ名目95%で、2つをまとめた誤検出率は制御していない。2つの差はS−を共有するので独立ではない。

S−は標準のEGS5にない人工的な設定である。飛行中の消滅の候補を無効な事象にし、その地点でエネルギーヒンジを引き直す（EGS5は離散事象の前にヒンジを打ち切るため、消滅の断面積を0にした輸送と数値的に同一ではない）。S− − S＋にはこの数値的な差が含まれうる。C− − S−にはPEGSの表の当てはめの違いが分離されずに残る。原因が確定したとは主張しない。
