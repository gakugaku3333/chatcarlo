# 追補1の事前登録の外の値（記述のみ、判定ではない）

本計算の結果を見たあとに作った表である。6 MeV、ビルドアップ（0.5 mm bin 6–43）の平均の差、% Dref（固定）、±はSEM。
作り方は `outside_plan.py`、数値は `outside_plan.json`。

| 差 | 値 |
|---|---|
| 新C− − 新S＋（事前登録の量。各1,200万履歴） | +0.226 ± 0.126 |
| P2感度 − P2主（各約238万履歴） | +1.052 ± 0.286 |
| 新S＋ − P2主（同じ設定、seedと履歴数が違う） | +0.455 ± 0.220 |
| 新C− − P2感度（同じ設定、seedと履歴数が違う） | −0.371 ± 0.222 |
| dcslib − P2主 / − 新S＋ | +0.718 ± 0.290 / +0.263 ± 0.223 |
| mf − P2主 / − 新S＋ | +1.046 ± 0.279 / +0.591 ± 0.208 |
| elsepa − P2主 / − 新S＋ | +0.848 ± 0.303 / +0.393 ± 0.239 |

- 同じ設定どうしの差（3行目、4行目）は、統計のゆらぎだけなら0のまわりに分布する。P2の主は約2σ低く、P2の感度は約1.7σ高かった。向きが逆なので、P2の差が大きく見えた。
- P2の+1.05%は12の領域から事後に選んだ値なので、大きめに出ていた値を拾った可能性と整合する。ただしそれを証明したわけではない。
- 試作と新S＋の差は、P2の試作の計算（seedは別）を新しい基準に当てただけで、事前登録した比較ではない。P2の判定にもP2bの事後解析にも使わない。
