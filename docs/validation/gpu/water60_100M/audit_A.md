## 実施した独立検証

- `.venv/bin/python -m chatcarlo validate runs/diag_water_60kev_gpu/scene.yaml`を再実行し、警告なしで有効。水はz=0〜20 cm、線源z=-0.0001 cmで、水内部に埋没しない。物体は1個で重複なし。単色研究線源なので、管電圧・濾過の臨床撮影条件は該当しない。
- bundleの実物比較により、旧・追加間の物理入力・実装・係数表が同一であることを確認。
- 旧ログの50,000,000履歴、100新規バッチをjob・NPZと照合。履歴数比=1、バッチ数比=1。
- 各群のバッチ数を \(M_1,M_2\)、平均を \(\mu_1,\mu_2\)、平均の標準誤差を \(e_1,e_2\)、\(M=M_1+M_2\) とすると、等サイズバッチの統合SEMは次式：

\[
e^2 =
\frac{M_1(M_1-1)e_1^2+M_2(M_2-1)e_2^2+
(M_1M_2/M)(\mu_1-\mu_2)^2}
{M(M-1)}
\]

今回は \(M_1=M_2=100\)。平均は両平均の算術平均、`n_batches_hit`とraw加算量は両runの和、Rは統合SEM÷統合平均となる。合成した200バッチを直接計算する独立検証で、分散比は丸め誤差内で1だった。
- 旧NPZの`SEM/mean`と保存Rの最大絶対差は \(2.78\times10^{-17}\)。
