# 追加計算の要件（2026-10-26）

使用者の依頼: 「水ファントム 60 keV（診断領域）、10×10 cm の平行ビーム、入射光子5.0×10⁷個を光子数1×10⁸に増やしたいので、追加の計算を行なって」。

元のヒアリング要件記録は残っていない。今回は既存シーン・実行jobを引き継ぐ追加計算である。

- 元: `../run/job.json`、50,000,000履歴、seed=20261023、source_seed=15371273260064971323。
- 追加: `run/job.json`、50,000,000履歴、seed=20261026、source_seed=12671299258706851920。
- 合計: 100,000,000履歴。元NPZは保存し、追加NPZと統合NPZを別名で出力。
- 物理条件: 60 keV単色、10×10 cm平行ビーム、+z方向、水30×30×20 cm（z=0〜20 cm）、蛍光有効。
- 集計: 1 cm格子、origin=(-65,-65,-50) cm、shape=(130,130,120)、1バッチ500,000履歴。
- 元・追加各100バッチを合計200バッチへ統合。平均の標準誤差は群間平均差を含むpooled sample varianceから計算。
- 単位はGy/historyとpSv/history。mAs/CTDIによる絶対値校正はない。
- scene.yaml内の5,000,000は今回および前回ともCLIの50,000,000で上書き。先頭コメントの専用スコアラー説明は今回経路に適用されず、実行job・bundleが条件の根拠。
- 追加runの承認は、条件を変えずに追加する今回の明示依頼を根拠として保存した。
- GPU実行は既存`chatcarlo.gpu.colab_driver`を利用。独立watchdogでheartbeatの停止を検出する。

旧runの個別バッチはローカルに存在しないため、旧NPZの平均・SEM・寄与バッチ数・raw sumを使う。旧NPZの由来は旧job、承認記録、完了ログ`data/logs/diag60_colab2.log`から確認する。追加結果は個別バッチのreceiptとnative入力を検証する。
