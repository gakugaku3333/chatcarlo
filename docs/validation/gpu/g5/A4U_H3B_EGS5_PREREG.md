# 事前登録: H3b の 14–15 keV を切り分けるための EGS5 新規 1 本（2026-11-04）

**この文書は結果を見る前に書いた。** 判定の規則・履歴数・条件をここで固定し、走ったあとで変えない。
ユーザー指示（2026-11-04）「EGS5 を 1 本追加」。計画の D8・D13 (ii) が禁じていた新規の EGS5 を、
ユーザーの判断で 1 本だけ解禁する。

## 答えたい問い

H3b の事前登録の帯のうち **14–15 keV だけ** が ChatCarlo / EGS5 = 0.852 で残っている
（[A4U.md](A4U.md)「小区間に割ると、未説明はどこか」）。この帯は鉛の L2N4（14.765 keV）が主。
こちら側は照合が尽きている:

| 確かめたこと | 結果 |
|---|---|
| 表の μ 対 xraylib | 1.000 |
| 表の μ 対 保存済み PEGS5 | 1.000 |
| 線の分岐（EGS5 の `DFLX2` 対 xraylib） | 0.1641 対 0.1615（1.6% 差） |
| L2 空孔数（12–13 keV が同じ空孔由来で −3.6%） | 整合 |
| 輸送（深さ 5・25 µm に 14.765 keV を等方注入 対 無衝突の解析解） | 1.03〜1.08 倍（Rayleigh の戻り分） |

残る候補は **EGS5 側だけが持つ 14.765 keV 付近の源** —— 電子を運ぶことで生じる制動放射、
または電子衝撃イオン化（EII、`impacr`／`egs5_eii.f`）による L 空孔。診断の特殊化は
`local-deposition` で電子を運ばないので、どちらも原理的に持たない。

## 走らせるもの（1 本）

保存済み `docs/egs5_crosscheck/fluorescence/fluor_on` と**同じ幾何・同じ物理の旗・同じ seed**:
鉛 0.05 cm、100 keV の鉛筆ビーム垂直入射、`IRAYL=1,IBOUND=1,INCOH=1,ICPROF=0`、
`iedgfl(2)=1`、`iauger(2)=0`、AE=0.521・AP=0.001 MeV、電子の打ち切り 10 keV、inseed=1、
100 万履歴。**変えるのは採点だけ**: 脱出光子を**起源で分けて** 1 keV のヒストグラムに入れる。

| 類 | 定義 | LATCH の立て方 |
|---|---|---|
| R | 緩和由来（蛍光・CK の連鎖で生まれた光子とその子孫） | 既存の `iarg=19`（光電吸収の直前）の +100000 をそのまま使う |
| B | **制動放射由来とその子孫** | **`iarg=7`（制動放射の直後。`egs5_collis.f:277,346,401` で確認）** に新しい桁を足す。`iausfl(8)=1` を立てる |
| P | 一次とその散乱（無衝突・Compton・Rayleigh） | 既存の `iarg=17`（+1）・`iarg=23`（+1000）の分類をそのまま使う |

**2026-11-04、走らせる前に直した 2 点**（操作のコード `fluor_on.f` と EGS5 の源を読んだ結果）:

1. **EII の類は作らない**。`impacr` は `egs5_block_set.f:52` で既定 0 で、`fluor_on.f` は
   どこにも設定していない（`iausfl` の 3 行だけ）。つまり**保存済みの走行では電子衝撃イオン化は
   無効**。電子由来の光子の源は制動放射だけなので、R と B の 2 分で足りる。
   なお EII の `ausgab` は `iarg=4`（`egs5_eii.f:121`）で、これは既定で有効な
   「その場の沈着」の通し番号と同じなので、仮に有効でも `iarg` では分けられない。
2. **既存の出力ではこの問いに答えられないことを確認した**（新規 1 本が必要な理由）。
   `fluor_on.f` の `ausgab` は脱出光子を `latch>=100000` で「蛍光（光電の子孫）」=jj=4 に分類するが、
   光電吸収の直前に立てた +100000 は**光電子にも継承される**ので、その光電子が出した
   制動放射の光子も jj=4 に入る。つまり保存済みの jj=4 は**蛍光と制動放射の混ざり**で、
   1 keV のヒストグラム `ebin` も起源を分けていない。

**桶の対応も確認した**: `ausgab` の `ibin=int(e/bwidth+0.999)` は実質 `ceil(E[keV])` なので
`ebin(j)` は (j−1, j] keV。L2N4（14.765 keV）は `ebin(15)` に入り、
ChatCarlo の bin 14 = [14,15) と同じ帯を指す（こちらの抽出もこの対応で行っている）。

合計が既存の `fluor_on` のヒストグラム（総脱出 309706 件）と**同じ seed で一致すること**を
健全性の検査にする（採点を足しただけで物理を変えていないことの確認）。一致しなければ止める。

## 判定（結果を見る前に固定）

ChatCarlo の本番（400 万履歴、`a4u_h3b.json` の条件 SHA256 `caebfcb1…`）の 14–15 keV は
**1002 件／400 万 = 2.505e-4 /履歴**。EGS5 の全体は **1176/4 = 294 件／100 万 = 2.94e-4 /履歴**。

- **(1) R が 2.505e-4 ± 2σ に入る**（すなわち R ≈ 1002/400 万相当で、差の大半が B）
  → **こちらの緩和は EGS5 と合っている**。残差は「電子を運ばない模型の差」と確定する。
  H3b の帯の判定を R だけで取り直し（事前登録のこの文書の規則として許す）、
  帯が 2σ/5% に入れば H3b を**合格**とし、入らなければ不合格のまま。
- **(2) R が EGS5 の全体 2.94e-4 に近く（B が 14–15 keV の 5% 未満）**
  → 残差は **L 線の分岐データの差**（Table of Isotopes 対 EPDL）。H3b は**不合格のまま**閉じ、
  「参照データの差」として記録する。実装は直さない。
- **(3) どちらでもない（B が差の一部だけ）** → 両方を量で書き、H3b は不合格のまま。
  追加の EGS5 は**回さない**（1 本だけという約束を守る）。

いずれの場合も、**分岐した 4 量（`s2:category:3:*`）を「EGS5 で検証済み」とは呼ばない**（D13 (ii)）。
この 1 本は 14–15 keV の起源を分けるためだけのもので、検出器の ROI の観測量は測らない。
