## 実装

- 検証側のexportがP9aのseed材をID 4として封印する。33配列と密度のピン追記は、Claudeがexportを実行するまで未生成。既存4材料のピンは変更していない。
- 旧0.25 mmから共通マスクを固定。近傍25,400セル、前立腺186,140、直腸193,480。
- 50対バッチ、各門71429/バッチ、各側25,000,150光子。14門対が揃ったcheckpointだけを原子的に更新する。
- 最終native引数の幾何・材料・物理ID/tag・履歴範囲を観測し、承認条件と照合する。
- 単一snapshot tarで回収。再開・再送・不完全な対・範囲外・欠落を検査する。
- 独立参照の固定、B3の7量の判定、同一VMでのB5測定、T4 notebookの生成を検証側へ用意した。
- 4つの承認用ディレクトリは1つの封印済みbundleを参照し、転送partsは送信後に削除する。

**全体2コマンドは、ユーザーの指示に従ってキャッシュの実データを読む検査を除外して実行した。**
一時的な`sitecustomize.py`のaudit hookが`~/.cache`へのファイルアクセスをSkipTestで止め、
`PYTEST_PLUGINS`の一時pluginでキャッシュ依存の子プロセス2件を実行前にskipした。
このguard/pluginはリポジトリや製品には追加していない。
最初の試作側実行では、その2件が子プロセスに伝わったSkipTestを失敗として数えた
（1421成功・402skip・2失敗）。最終の404skipにはこの2件を含む。
キャッシュを含めた無条件の全テスト成功を主張するものではない。Claude側でガードなしの2コマンドを再実行する。

追加26件には、材料ID/欠落/配列/ピン/密度の改変拒否、一定エネルギー密度の旧新一致、
49/50バッチの完了境界、途中の対・再送、履歴範囲の連続、native引数と材料の改変検出、
採点欠落/位置ずれ/出力欠落/履歴重複の故障注入、B3のpass/fail/統計不足を含む。
`prototypes`のimportを（既にロード済みのものも）禁止し、validate・preview・承認・
実bootstrap/listingを使う偽VMのrun/失敗/再開/解析まで通した。
CPU transportの人工入力は10 keV未満の光子であり、治療の物理精度を検証したものではない。

物理/RNGの共有83関数を凍結参照と照合した。
積層用に展開したCUDAソースは変更前とバイト一致：
`c39b6f72f0579ecbcf2f55f287261d20d0519296cc9ecc771d11a0e78f203624`。
既存の積層のC++本文、P7の100バッチ、診断の既定物理は変更していない。
