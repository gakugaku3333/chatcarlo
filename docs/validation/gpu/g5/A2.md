判定アダプターは P7 の `dose → compare → stop_on_missing` と `symmetry`、積層の `p8f_core.judge(..., dref=DREF)` を呼ぶ。
判定コード・閾値は書き直していない。解析前に A0 の参照ハッシュと pilot_lock を確認し、バッチファイルを読む入口では N・seed・start・組・健全性・SHA256 を確認する。
保存済み旧 GPU の回帰検査では、アーカイブをストリームで読み、必要なバッチの表のみを取り出す。

固定の `E-capacity` ケースは、運動エネルギーを全量付与した後、静止消滅光子を積む前に容量不足となる。旧い核と同じく失敗数が増え、未処理の運動エネルギー欄は 0 と記録される。他の容量・maxsteps ケースでは未処理エネルギーが正になる。故意の失敗の検査を本番の「失敗 0」と混同しない。
