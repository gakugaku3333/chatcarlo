### Claude の実行手順

1. 表3の外部データを復元し全manifest/封印を照合する。不一致・欠落ならそのまま記録し停止する。
2. P7/P8g-2 の既存の封印済みexportを用意する（必要なら既存export手順で再生成）。診断の束は起動役が bundle.create でホスト生成する。Mohan値をリポジトリへ写さない。
3. 新しいT4セッション名と新しい出力フォルダで起動する。

```bash
PYTHONPATH=. nohup .venv/bin/python docs/validation/gpu/g5/a0_launch.py \
  --session g5a0-first \
  --p7 /absolute/path/to/p7/export --p8g2 /absolute/path/to/p8g2/export \
  --output /absolute/path/to/fresh/a0-results > /absolute/path/to/a0-launch.log 2>&1 &
# PID=$! を控え、kill -0 "$PID" と heartbeat.json/watchdog.json を別に監視する
```

起動役は全colab呼出をtimeout付きにし、10分間隔のexec、毎回のJSON/ncu/log回収、finallyのstopを行う。独立プロセスがheartbeatを監視する。VMの起動はflock/PID/job SHAで排他し、G5A0_DONEが終了印。セッション断・健康不合格では基準を採らない。

4. 回収した測定JSONを read_results で検証し、表5・許容比とRESULTSの段結論を記入する。ncu生出力は手元で解析し、資源の手計算/occupancy APIと並べる。必要なら規則通り全6構成を再測定する。
5. 生 .ncu-rep は ~/.cache/chatcarlo/g5/a0/（50MB超はDrive）。測定JSON・健康・資源・CSV・取得記録をこのフォルダへ保存する。線量/履歴の一時配列・転送束/断片は健康JSONの保存後に削除する。
