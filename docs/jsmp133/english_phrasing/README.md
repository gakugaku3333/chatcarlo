# 英語抄録の言い回し調査（Claude・Codex 共有）

作成: 2026-10-28（Claude）。英訳元は [../abstract_ja_draft.md](../abstract_ja_draft.md) の「②⁺ 正式採用の抄録本文（登録用 v5）」。

このフォルダは、英語抄録を書くときに Claude と Codex が同じ資料を見られるように置いている。

| ファイル | 中身 |
|---|---|
| [sources.md](sources.md) | 調べた関連論文の一覧（題名・著者・年・URL）と、各論文から参考にする点 |
| [phrasebook.md](phrasebook.md) | v5 の日本語の語句ごとの英語の候補、その根拠になる論文、決めるべき点 |
| [ai_writing_guidelines.md](ai_writing_guidelines.md) | AI と抄録・論文・スライドを作るときの注意（開示・AI 特有の語・スライドの形） |

## 使い方と注意

- 論文の本文は保存していない（著作権のため）。全文が要るときは sources.md の URL から読む。arXiv の論文は誰でも読める。
- phrasebook.md の英語の候補は、関連論文で一般に使われている専門用語や定型表現を、Claude が自分の文としてまとめたもの。論文の文をそのまま写していない。抄録にも論文の文を写さない。
- 数値と評価範囲は v5 と ③ の出典が正典。英訳で数値を変えない。
- 「未決」と書いた語は、英文を書く前に使用者と決める。
