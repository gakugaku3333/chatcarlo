## 調整で外した・置き換えた項目（段階 2〜3）

- 動画（MP4）は作らない（使用者「コマ送り画像でよい」）。
- 共通の濃淡の並べ図は、入口が出した NPZ から作る CLI の外の後処理（入口の PNG は 1 枚ごとに濃淡を自動調整するため）。
- ヒール効果なし（GPU エンジンの制限。使用者「なしで進める」）。
- 実際の検出器の効率・エネルギー応答・電気的ノイズは含まない。10⁸ 個でも一般撮影（数 mAs）の約 1/1000 の線量。
- 記録: この通しを始めた時点で、vive-interview の対応表は「検出器面の画像は入口から出せない」と古いままだった（G4、2026-10-21 で可能になっていた）。段階 2 では `run --help` と G4 の記録を正とした。
