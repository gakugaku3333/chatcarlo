> **Purpose**
> モンテカルロ計算の実施には、専門的な入力形式の習得と、十分な統計精度を得るための計算資源という 2 つの障壁がある。本研究では、条件設定を AI との対話で行い、計算をクラウド上で実行することで、モンテカルロ計算を容易に実行できるシステムを構築することを目的とした。
>
> **Methods**
> Claude Code（Anthropic）を用いて、最大 10 MeV の光子・電子・陽電子輸送を扱うモンテカルロコードと、これを対話型の AI エージェントで操作するシステムを構築した。AI エージェントの動作は、汎用の手順書形式 Agent Skills で定義し、Claude Code や Codex（OpenAI）等で利用可能とした。AI は計算目的の聞き取り、計算方法の検討、出力形式の確認を対話で順に行い、確定した条件から計算の入力を自動生成する。使用者が 3D 表示で条件を承認した後、Google Colaboratory（Google）の GPU で計算が実行される。
> 評価 1 として、水ファントム（10×10 cm、60 keV・10 MV）の PDD と OCR、および水・肺・骨・鉛の積層ファントムの PDD を EGS5 と比較した。差は各点の EGS5 の値に対する局所の割合とし、PDD はビルドアップを含む全域、OCR は照射野内（50% 幅の 80% 以内）で評価した。MV のペナンブラは 50% 位置のずれで評価した。入射光子数は、60 keV で 5.0×10⁷、10 MV と積層で 1.0×10⁸ とした。
> 評価 2 として、性質の異なる 3 件の計算依頼（IVR 室の H*(10) 分布、入射光子数を変えた X 線画像、前立腺内の I-125 シードが外照射の線量分布に与える影響）を対話で実施した。入射光子数は、IVR 室で 1.0×10⁸、シードの計算でシードの有無の各 3.0×10⁸ とし、X 線画像では 10⁴ から 10⁸ まで 5 段階で変えた。
>
> **Results**
> 評価 1: 60 keV では、PDD の差は平均 0.21%、最大 1.0%、照射野内の OCR では平均 0.23%、最大 0.3%だった。10 MV では PDD の差は平均 0.53%、最大 1.5%、照射野内の OCR では平均 0.43%、最大 1.2%、50% 位置のずれは 0.1 mm 以内だった。積層の PDD は平均 0.17%、最大 1.3%だった。
> 評価 2: IVR 室では、対話で設定した条件の H*(10) 分布を計算し、3D の線量分布を得ることができた。X 線画像では、画像ノイズが低下していく過程が視認できた。シードの計算では、シードの表面から 1 mm 以内で線量が最大 3.3% 増加し、2〜3 mm でほぼ元に戻った。前立腺全体の平均では +0.5% であった。
>
> **Conclusion**
> 構築したシステムは、検証した条件で EGS5 との差は平均 1% 未満、最大 1.5% であり、性質の異なる 3 件の計算依頼を対話で実施できた。
