# 依頼 D（JSMP133 依頼 2）: 事前に決めた条件

初版: 2026-10-21（コミット 7b275ec）。**改訂版: 2026-10-21**（この版）。どちらも本計算の解析の前に書き、コミットした。
結果を見てから条件を選び直さない。判定から外れても、そのまま報告する。

## 改訂の理由と経緯

- **ユーザーの決定による被写体の変更。** 初版の被写体（軟部組織の板 8 cm と骨の円柱）を、レントゲン博士の肖像を
  アルミの凹凸板にしたものに変えた。発表で「ノイズから肖像が浮かび上がる」様子を見せるため。
- さらにユーザーの指示で、照射野を肖像の範囲だけに絞った（枠の外へ光子を飛ばす計算時間を省くため）。
  そのため均一領域は、肖像の中の一様な背景（いちばん厚い段階）に取った。
- 初版の条件で 10^4〜10^7 の 7 段階×2 本を計算したが、変更の連絡を受けて止めた。**その結果は解析していない**
  （見たのは所要時間と検出面に達した履歴数だけ）。結果は捨てずに
  `~/.cache/chatcarlo/jsmp133_request_d/v1_bone_softtissue_unanalyzed/` に残した。初版のシーン
  [scene_bone_softtissue.yaml](scene_bone_softtissue.yaml) も記録として残す。
- 改訂で変えたのは、被写体・照射野・検出器の大きさ・ROI の位置。履歴数の段階、乱数の種、主の指標（2 本の差）、
  補助の指標、判定の幅、濃淡目盛りの決め方は初版のまま。

## 何を示すか（と、示さないもの）

- 示すのは、**モンテカルロの履歴数 N を増やすと、計算結果（検出器画像）の統計誤差が減る**こと。
  同じ撮影条件・同じ被写体で N だけを変える。均一領域の相対誤差が約 1/√N（両対数で傾き −0.5）で減るかを見る。
- **示さないもの: mAs（撮影時の量子ノイズ）。** シーンに `mas` を付けていないので、出力は履歴あたりの量で、
  実際の光子数への校正は入らない（意図した選択）。画像のざらつきは**計算の統計誤差**であり、
  実際の X 線画像の量子ノイズではない。重みつきの履歴を、実際に検出された光子と見なさない。
- 用語: 横軸は「履歴数 N」。検出面に達した履歴の数は「検出面に達した履歴数」と呼び、「光子数」とは書かない。

## 画像に使う量

- **総エネルギーフルエンス（一次線 + 散乱線 + 蛍光、4 区分の和）を履歴数で割ったもの**
  Ψ/N [keV cm⁻² / 履歴]（`category_fluence.sum(axis=0) / N`）。理想的なエネルギー積分型の検出器に相当する。
- 配列は `category_fluence[cat, iu, iv]`。`iu` は u 軸（+x）、`iv` は v = 法線 × u = +y の向き。
  表示では転置して、横 = x、縦 = y（上が頭）にする。

## 履歴数の段階、乱数、並列

- 9 段階、半桁ごと: N_k = round(10^(4 + 0.5k))、k = 0〜8
  = 10000, 31623, 100000, 316228, 1000000, 3162278, 10000000, 31622777, 100000000。
- 各段階で**独立な 2 本**（A、B）を回す。乱数の種は A = 2000 + 10k、B = 2001 + 10k。段階どうしも独立
  （累積ではない）。
- ワーカー数: N ≤ 1,000,000 は 1、それより大きい段階は 8。ワーカー数で乱数列は変わるが、統計的には同等。
- バッチの大きさ: min(200000, ceil(N/10))。バッチの R は補助の指標なので、バッチ数が段階で多少違ってもよい。

## 均一領域（ROI）

- 肖像の背景（段階 5 = アルミ 8.5 mm が一様な所）の左上と右上に 2 か所。検出器の画素で
  左: iu = 13〜28、iv = 88〜109（`[13:29, 88:110]`）、右: iu = 73〜88、iv = 88〜109（`[73:89, 88:110]`）。
  各 16×22 = 352 画素、合わせて 704 画素を 1 つの ROI として扱う。検出面で左は x = −5.55〜−3.15 cm、
  右は x = 3.45〜5.85 cm、どちらも y = 4.2〜7.5 cm。
- 均一だという根拠（厚さの地図と幾何学だけで決めた。計算結果は見ていない）:
  - 段階の地図で、段階 5 の領域を 1 画素ぶん内側に縮めても、左は列 2〜10・行 2〜14、右は列 32〜40・行 2〜14 が
    すべて段階 5（行 0 が上）。板の上で左は x = −5.7〜−3.0、右は x = 3.3〜6.0、y = 3.9〜7.8 cm。
  - 板の拡大率は 1.01（下面）〜1.019（上面）。検出面の ROI を板の高さに戻すと、左は x = −5.50〜−3.09、
    右は x = 3.39〜5.79、y = 4.12〜7.43 cm で、上の範囲の内側に入る。
  - 照射野の端（検出面で y = 8.6 cm、x = ±6.45 cm）から 1.1 cm 以上離れている。
  - ROI ではアルミ 8.5 mm だけを通る。残る濃淡は、距離の逆二乗・斜入・散乱線のゆるやかな傾きだけ。

## 指標（主・補助）

1. **主: 差の画像による相対誤差。** 同じ N の A と B の画像 I_A、I_B について、ROI（704 画素）で
   CV_diff = std(I_A − I_B, ddof=1) / √2 / mean((I_A + I_B)/2)。決まった形の濃淡は差をとると消えるので、
   計算の統計誤差だけが残る。
2. 補助 1: A だけの画像で、左右の ROI にそれぞれ 1 次の平面（a + b·x + c·y）を最小二乗で当てて引き、
   CV_plane = sqrt(残差の二乗和 / (704 − 6)) / mean(I_A の ROI)。
3. 補助 2: 複合ポアソンの予測。A の ROI で λ = 画素あたりの検出面に達した履歴数の平均（`photon_count` の平均）、
   ⟨E⟩ = Σ`energy_sum_keV` / Σ`photon_count`、⟨E²⟩ = Σ`energy_sum2_keV2` / Σ`photon_count`。
   CV_pred = sqrt(⟨E²⟩/⟨E⟩² / λ)。「ばらつきは計算の統計誤差だけで説明できるか」の独立の確認。
4. 補助 3（参考のみ、判定に使わない）: A の ROI でのバッチ R（`total_relative_error`）の中央値と、寄与した
   バッチ数の中央値。N が小さいと寄与バッチ数が少なく、小さい R は信用できない（CLAUDE.md の R の指針）。

## 傾きの当てはめと判定

- log10(CV_diff) を log10(N) に対して、9 段階すべてで普通の最小二乗で直線を当てる。傾きとその標準誤差を出す。
- **判定: 傾きが −0.55〜−0.45 なら「約 1/√N に従った」とする。** あわせて、各段階の CV_diff / CV_pred を出し、
  0.8〜1.2 に入るかを見る（入らない段階はそのまま報告する）。
- CV_plane も同じ当てはめをして並べる（判定には使わない）。
