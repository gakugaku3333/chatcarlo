## 何を示すか（と、示さないもの）

- 示すのは、**モンテカルロの履歴数 N を増やすと、計算結果（検出器画像）の統計誤差が減る**こと。
  同じ撮影条件・同じ被写体で N だけを変える。均一領域の相対誤差が約 1/√N（両対数で傾き −0.5）で減るかを見る。
- **示さないもの: mAs（撮影時の量子ノイズ）。** シーンに `mas` を付けていないので、出力は履歴あたりの量で、
  実際の光子数への校正は入らない（意図した選択）。画像のざらつきは**計算の統計誤差**であり、
  実際の X 線画像の量子ノイズではない。重みつきの履歴を、実際に検出された光子と見なさない。
- 用語: 横軸は「履歴数 N」。検出面に達した履歴の数は「検出面に達した履歴数」と呼び、「光子数」とは書かない。

## 計算の道具

- 本番の `chatcarlo/`（診断領域、150 keV 上限）の NumPy 輸送 `run_transport`。平面検出器のタリーは
  `chatcarlo/detector.py`。`--engine kernel`（Numba）は検出器タリーに対応していない（`run_transport` が拒否する）
  ので、本番の NumPy 輸送を使う。GPU は使わない。`chatcarlo/` のコードは変えない。
- 計算: [run_history_noise.py](run_history_noise.py)。解析: `analyze_history_noise.py`（本計算の後に書く。中身は
  下の定義どおり）。

## 被写体と撮影条件（[scene_bone_softtissue.yaml](scene_bone_softtissue.yaml)）

- 線源: 70 kVp、総ろ過 2.5 mmAl（SpekPy スペクトル）、焦点 (0, 0, 100) cm から −z 方向、矩形照射野 20×20 cm
  （SID 100 cm）。ヒール効果なし（既定）。`mas` なし。
- 被写体: 軟部組織（ICRP）の板 24×24×8 cm、中心 (0, 0, 6)（z = 2〜10 cm）。その中に骨（ICRP 皮質骨）の円柱、
  半径 1.25 cm、y 方向の長さ 18 cm、中心 (−4, 0, 6)。周りは空気。蛍光 X 線あり（既定）。
- 検出器: z = 0 の平面、20×20 cm、128×128 画素（画素 0.15625 cm）、法線 +z。理想的な終端型（到達した光子を
  そこで止める）。

## 画像に使う量

- **総エネルギーフルエンス（一次線 + 散乱線 + 蛍光、4 区分の和）を履歴数で割ったもの**
  Ψ/N [keV cm⁻² / 履歴]（`category_fluence.sum(axis=0) / N`）。理想的なエネルギー積分型の検出器に相当する。
- 配列は `category_fluence[cat, iu, iv]`。`iu` は u 軸（+x）、`iv` は v = 法線 × u = +y の向き。
  表示では転置して、横 = x、縦 = y にする。

## 履歴数の段階、乱数、並列

- 9 段階、半桁ごと: N_k = round(10^(4 + 0.5k))、k = 0〜8
  = 10000, 31623, 100000, 316228, 1000000, 3162278, 10000000, 31622777, 100000000。
- 各段階で**独立な 2 本**（A、B）を回す。乱数の種は A = 2000 + 10k、B = 2001 + 10k。段階どうしも独立
  （累積ではない）。
- ワーカー数: N ≤ 1,000,000 は 1、それより大きい段階は 8。ワーカー数で乱数列は変わるが、統計的には同等
  （CLAUDE.md の Commands 参照）。
- バッチの大きさ: min(200000, ceil(N/10))。バッチの R は補助の指標なので、バッチ数が段階で多少違ってもよい。

## 均一領域（ROI）

- 画素 iu = 88〜103、iv = 56〜71（`[88:104, 56:72]`、16×16 = 256 画素）。検出面で x = 3.75〜6.25 cm、
  y = −1.25〜1.25 cm。
- 均一だという根拠（幾何学だけで決めた）: 焦点 z = 100 cm から高さ z の点は検出面で 100/(100 − z) 倍になる。
  - 骨の影: 円柱の x = −5.25〜−2.75 cm、z = 4.75〜7.25 cm → 検出面で x ≈ −5.66〜−2.89 cm。ROI から 6.6 cm 以上
    離れている。
  - 板の影: x, y = ±12 cm（z = 2〜10）→ 検出面で ±12.2 cm 以上。検出器（±10 cm）の外。
  - 照射野の端: 検出面で ±10 cm。ROI から 3.75 cm 以上離れている。
  - ROI の中は軟部組織 8 cm だけを通る。残る濃淡は、距離の逆二乗・斜入・散乱線のゆるやかな傾きだけ。

## 指標（主・補助）

1. **主: 差の画像による相対誤差。** 同じ N の A と B の画像 I_A、I_B について、ROI で
   CV_diff = std(I_A − I_B, ddof=1) / √2 / mean((I_A + I_B)/2)。決まった形の濃淡（逆二乗、散乱線の傾き）は
   差をとると消えるので、計算の統計誤差だけが残る。
2. 補助 1: A だけの画像で、ROI に 1 次の平面（a + b·x + c·y）を最小二乗で当てて引き、
   CV_plane = std(残差, ddof=3) / mean(I_A)。
3. 補助 2: 複合ポアソンの予測。A の ROI で λ = 画素あたりの検出面に達した履歴数の平均（`photon_count` の平均）、
   ⟨E⟩ = Σ`energy_sum_keV` / Σ`photon_count`、⟨E²⟩ = Σ`energy_sum2_keV2` / Σ`photon_count`。
   CV_pred = sqrt(⟨E²⟩/⟨E⟩² / λ)。「ばらつきは計算の統計誤差だけで説明できるか」の独立の確認。
4. 補助 3（参考のみ、判定に使わない）: A の ROI でのバッチ R（`total_relative_error`）の中央値と、寄与した
   バッチ数の中央値。N が小さいと寄与バッチ数が少なく、小さい R は信用できない（CLAUDE.md の R の指針）。

## 傾きの当てはめと判定

- log10(CV_diff) を log10(N) に対して、9 段階すべてで普通の最小二乗で直線を当てる。傾きとその標準誤差を出す。
- **判定: 傾きが −0.55〜−0.45 なら「約 1/√N に従った」とする。** あわせて、各段階の CV_diff / CV_pred を出し、
  0.8〜1.2 に入るかを見る（入らない段階はそのまま報告する）。
- CV_plane も同じ当てはめをして並べる（判定には使わない）。
