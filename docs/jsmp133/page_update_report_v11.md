### 変更前

Purpose

モンテカルロ計算の実施には、専門的な入力形式の習得と、十分な統計精度を得るための計算資源という 2 つの障壁がある。本研究では、条件設定を AI との対話で行い、計算をクラウド上で実行することで、モンテカルロ計算を容易に実行できるシステムを構築することを目的とした。

Methods

Claude Code（Anthropic）を用いて、最大 10 MeV の光子・電子・陽電子輸送を扱うモンテカルロコードを Python で記述し、GPU（CUDA）で実行できるようにした。光子の断面積には NIST の公開データなどの評価済みデータ、電子の弾性散乱には公開コード ELSEPA を用いた。さらに、このコードを対話型の AI エージェントで操作するシステムを構築した。AI エージェントの動作は、汎用の手順書形式 Agent Skills で定義し、Claude Code や Codex（OpenAI）等で利用可能とした。AI は計算目的の聞き取り、計算方法の検討、出力形式の確認を対話で順に行い、確定した条件から計算の入力を自動生成する。使用者が 3D 表示で条件を承認した後、Google Colaboratory（Google）の GPU で計算が実行される。

評価 1 として、水ファントム（10×10 cm）の 60 keV での PDD と OCR、および水・肺・骨・鉛の積層ファントムの 10 MV での PDD を EGS5 と比較した。差は各点の EGS5 の値に対する局所の割合とし、PDD はビルドアップを含む全域、OCR は照射野内と照射野端から外側 3 cm までで評価した。入射光子数は、60 keV で 1.0×10⁸、積層で 1.0×10⁸ とした。

評価 2 として、性質の異なる 2 件の計算依頼（入射光子数を変えた X 線画像、前立腺内の I-125 シードが 10 MV の外照射の線量分布に与える影響）を対話で実施した。入射光子数は、X 線画像では 10⁴ から 10⁸ まで 5 段階で変え、シードの計算ではシードの有無の各 3.0×10⁸ とした。

Results

評価 1: 60 keV の水ファントムでは、PDD の差は平均 0.16%、最大 0.6%、OCR では平均 0.39%、最大 1.3%だった。10 MV の積層ファントムの PDD は平均 0.17%、最大 1.3%だった。

評価 2: X 線画像では、画像ノイズが低下していく過程が視認できた。シードの計算では、シードの表面から 1 mm 以内で線量が最大 3.3% 増加し、表面から約 2 mm でほぼ元に戻った。前立腺全体の平均では +0.5% であった。

Conclusion

構築したシステムは、検証した条件で EGS5 との差は平均 0.4% 未満、最大 1.3% であり、性質の異なる 2 件の計算依頼を対話で実施できた。
